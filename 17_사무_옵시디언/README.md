# 17. 내 메모 창고

> **얻는 능력:** 쌓인 메모 창고(옵시디언)를 Claude에게 맡겨 **연결 안 된 노트 찾기, 태그 정리, 주간 요약**을 받는 능력

**왜 배우나요?** 메모는 쓰는 것보다 **다시 찾는 게** 어려워요. 링크 하나 없이 외딴섬이 된 노트(고아 노트)는 영영 잊히죠. Claude가 창고 전체를 훑어 정리해 주면, 메모가 진짜 '두 번째 뇌'가 돼요. 비유하면 **도서관 사서**가 책장을 한 바퀴 돌며 꽂힌 위치를 정리해 주는 거예요.

## 📁 들어 있는 파일
- `연습보관함/` – 취미·독서·아이디어에 관한 가짜 노트 15개 (`[[링크]]`, `#태그`, 머리말 `날짜:` 포함)
- `정답_고아노트.md` – 고아 노트·깨진 링크·주간 요약 대상 정답 (**채점 전까지 열지 않기!**)

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 확인해요.

**준비 (직접):** 옵시디언 앱을 설치하고 **폴더를 보관함으로 열기 → `연습보관함`** 을 골라요. (진짜 내 보관함은 열지 않아요.)

**방법 A — MCP 없이 파일로 (먼저 이걸로!)**
옵시디언 노트는 그냥 `.md` 파일이에요. 연습보관함이 키트 폴더 안에 있어서 Claude Code가 **바로 읽고 쓸 수 있어요.** 설치할 것이 없어요.

**방법 B — 옵시디언 MCP (도전)**
옵시디언 회사가 만든 공식 MCP는 없어요. 가장 널리 쓰이는 건 커뮤니티 플러그인 **Local REST API**예요. 최신 버전에는 MCP 기능이 들어 있어요.
1. 옵시디언 → 설정 → 커뮤니티 플러그인 → **Local REST API** 설치·켜기 (직접). 검사표 1번(누가 만들었나)을 꼭 채워요.
2. 설정 → Local REST API에서 **API 키**를 복사해 키트 `.env`에 `OBSIDIAN_API_KEY=...`로 직접 넣어요.
3. 키트 폴더에서 직접 실행해요.
   ```bash
   claude mcp add-json --scope project obsidian '{"type":"http","url":"https://127.0.0.1:27124/mcp/","headers":{"Authorization":"Bearer ${OBSIDIAN_API_KEY}"}}'
   ```
   → 내 컴퓨터 안(127.0.0.1)의 옵시디언에 연결해요. 키 자리엔 이름표 `${OBSIDIAN_API_KEY}`만 저장돼요. 16강처럼 `export` 후 `claude`를 켜요.
4. 인증서 오류가 나면 플러그인 설명서의 HTTP 방법(27123 포트)을 봐요.

공식 안내: https://github.com/coddingtonbear/obsidian-local-rest-api (플러그인이 자주 바뀌어요. 안 되면 공식 문서에서 최신 방법을 확인해요.)
다 쓰면 `claude mcp remove obsidian -s project`, 플러그인 끄기.

## ⚠️ 알아 둘 것
- 방법 A는 **폴더를 정해 주는 게** 안전장치예요. 항상 "`연습보관함` 안에서만"이라고 말해요.
- **원본 노트는 고치기 전에 보여 달라고** 해요. 태그 추가처럼 고치는 작업은 미리보기 → 확인 → 적용 순서로.
- 노트 삭제·이름 바꾸기는 시키지 않아요. 이름을 바꾸면 다른 노트의 링크가 깨질 수 있어요.
- 옵시디언이 `연습보관함/.obsidian/` 설정 폴더를 만들어요. 지우지 말고 그대로 둬요.

## 🧭 기본 미션 (순서대로)
1. 옵시디언에서 **그래프 보기**를 열고, 혼자 떨어진 점(고아 노트)을 **내가 먼저** 세어 본다
2. 방법 A로 Claude에게 노트마다 **나가는 링크·들어오는 링크 수** 표를 만들게 한다
3. 고아 노트와 **깨진 링크**(없는 노트를 가리키는 링크)를 찾게 한다 → 1번 내 답과 비교
4. 태그 없는 노트에 붙일 태그를 **제안만** 받고, 내가 고른 태그만 넣게 한다
5. 머리말 `날짜:` 기준 2026-11-23~29 노트로 `연습보관함/주간 요약 2026-11-23.md`를 만들게 한다 (관련 노트는 `[[링크]]`로)
6. 옵시디언에서 주간 요약의 링크를 눌러 이동되는지 확인하고, `정답_고아노트.md`로 채점한다
