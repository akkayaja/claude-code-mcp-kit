# 정답 — 고아 노트 찾기 (채점 전까지 열지 않기!)

`연습보관함/`에는 가짜 노트 15개가 있어요.

## 1. 고아 노트 (3개)
이 키트에서 **고아 노트 = 다른 노트로 가는 링크도, 들어오는 링크도 하나도 없는 노트**예요.
- `뜨개질 시작하기`
- `영화 감상 - 겨울 기차`
- `아이디어 - 아침 루틴 체크표`

### 헷갈리기 쉬운 것
- `2026-11-29 일기` → 들어오는 링크는 없지만 `[[홈카페 레시피]]`로 **나가는** 링크가 있어요. 고아 아님. (옵시디언의 '들어오는 링크 없음' 기준으로는 4개가 나와도 이유를 설명하면 OK)
- `식물 키우기` → 나가는 링크는 없지만 `취미 모음`에서 **들어오는** 링크가 있어요. 고아 아님.

## 2. 깨진 링크 (1개)
- `아이디어 - 동네 책 교환` 안의 `[[아이디어 - 재활용 화분]]` → 그런 노트가 없어요.
