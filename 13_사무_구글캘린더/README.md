# 13. 일정

> **얻는 능력:** 글로 적은 일정을 Claude가 **캘린더에 넣고, 빈 시간과 겹치는 일정을 찾아 주는** 능력

**왜 배우나요?** 일정을 메모장이나 카톡에 적어 두면 캘린더에 옮기다 빠뜨리고, 겹치는 약속도 놓쳐요. Claude가 캘린더를 직접 다루면 "다음 주 2시간 비는 때 언제야?"에 바로 답해 줘요. 비유하면 **일정 관리 비서**에게 내 다이어리 한 권(연습용)만 맡기는 거예요.

## 📁 들어 있는 파일
- `일정_원본.md` – 2026년 12월 7~11일 한 주의 가짜 일정 메모 (시간 쓰는 방식이 제각각)
- `정답_겹치는일정.md` – 겹치는 일정·빈 시간 정답 (**채점 전까지 열지 않기!**)

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 확인해요.

구글 캘린더는 아직 연결 안 돼 있어요. **Claude 데스크톱 앱 커넥터**로 연결해요.
1. 데스크톱 앱(또는 claude.ai) **설정 → 커넥터**(사이드바 Customize → Connectors)에서 **Google Calendar**를 찾아 **연결**을 눌러요.
2. 구글 로그인과 **권한 허용 화면은 내가 직접** 읽고 눌러요. 어떤 권한(보기/수정)을 달라는지 검사표 2번에 적어요.
3. 다 쓰면 같은 화면에서 끄거나 **연결 해제**할 수 있어요. 구글 계정 → 보안 → 연결된 앱에서도 권한을 취소할 수 있어요.

공식 안내: https://support.claude.com/en/articles/10166901-use-google-workspace-connectors
커넥터가 할 수 있는 일(일정 만들기·수정)은 자주 바뀌어요. 연결 후 `/mcp` 또는 도구 목록에서 **일정 만들기 도구가 있는지** 직접 확인하고, 없으면 공식 문서에서 최신 방법을 확인해요.

**연습 공간 만들기 (직접):** 구글 캘린더 왼쪽 **다른 캘린더 + → 새 캘린더 만들기**에서 이름을 **`MCP연습`** 으로 만들어요. 오늘은 이 캘린더에만 넣어요.

## ⚠️ 알아 둘 것
- 캘린더 커넥터는 내 **진짜 일정**도 볼 수 있어요. 항상 "`MCP연습` 캘린더만"이라고 정해 줘요.
- 일정 **초대(참석자 추가)** 는 하지 않아요. 참석자를 넣으면 상대에게 초대 메일이 **보내져요**.
- 만약 도구가 기본 캘린더에만 넣을 수 있다면, Claude에게 **멈추고 알려 달라고** 해요. 진짜 캘린더에 연습 일정이 섞이면 지우기 번거로워요.
- 지우기는 연습 캘린더를 통째로 삭제하는 걸 **내가 직접** 해요.

## 🧭 기본 미션 (순서대로)
1. `일정_원본.md`를 읽고 **겹치는 일정이 있는지** 내가 먼저 찾아 메모한다
2. 구글 캘린더에 `MCP연습` 캘린더를 직접 만든다
3. Claude에게 넣을 일정 목록(날짜·시작·끝·제목)을 **표로 먼저** 보여 달라고 하고, 11개인지 확인한다
4. 확인이 끝나면 `MCP연습` 캘린더에만 일정을 넣게 한다 → 캘린더 화면에서 직접 본다 (기본 캘린더에 섞이지 않았는지도!)
5. 평일 09~18시 중 **연속 2시간 이상 빈 시간**과 **겹치는 일정**을 찾게 한다
6. `정답_겹치는일정.md`로 채점하고 결과를 `결과/일정_점검.md`로 저장한다

## 🔥 도전 미션 (기본을 끝냈다면)

- "블로그 글 마무리" 앞에 30분 준비 일정을 자동으로 붙여 달라고 하기
