# 정답 — 겹치는 일정과 빈 시간 (채점 전까지 열지 않기!)

## 1. 겹치는 일정 (1개)
- **12월 9일(수)**
  - 온라인 강의 3강: 13:00 ~ 14:30
  - 세탁소 이불 찾기: 14:00 ~ 14:30
  - → **14:00 ~ 14:30 이 30분 겹쳐요.**
  - 해결 예: 세탁소를 14:30~15:00으로 옮기기

## 2. 넣어야 할 일정 수
- 총 **11개** (월 2, 화 2, 수 3, 목 2, 금 2)
- 치과는 "1시간 정도" → 15:00~16:00 으로 들어가야 해요.

## 3. 평일 09:00~18:00 중 연속 2시간 이상 빈 시간 (점심 12~13시 제외)
| 날짜 | 빈 시간 |
|---|---|
| 12/7 (월) | 13:00 ~ 15:00 (2시간), 16:00 ~ 18:00 (2시간) |
| 12/8 (화) | 09:00 ~ 12:00 (3시간), 15:00 ~ 18:00 (3시간) |
| 12/9 (수) | 14:30 ~ 18:00 (3시간 30분) |
| 12/10 (목) | 09:00 ~ 11:00 (2시간), 13:00 ~ 18:00 (5시간) |
| 12/11 (금) | 13:00 ~ 16:00 (3시간) |

참고: 딱 2시간인 칸(월 13~15시, 월 16~18시, 목 9~11시)을 빠뜨리기 쉬워요.
화요일 저녁 요가, 목요일 저녁 답사는 18시 이후라 빈 시간 계산과 상관없어요.

## 채점 기준
- 겹침 1개를 찾고 몇 분 겹치는지 맞힘 → ⭐
- 11개가 모두 `MCP연습` 캘린더에 들어감 (기본 캘린더에는 0개) → ⭐
- 빈 시간 8칸(월 2, 화 2, 수 1, 목 2, 금 1)을 다 찾음 → ⭐
