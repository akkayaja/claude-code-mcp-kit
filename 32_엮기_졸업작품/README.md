# 32. 졸업 작품

> **얻는 능력:** 내 일 중 **반복되는 일 하나를 골라, MCP 2개 이상으로 자동화하고 남에게 보여 줄 수 있게** 완성하는 능력

**왜 배우나요?** 지금까지는 강의가 정해 준 길을 걸었어요. 졸업 작품은 **내가 길을 그리는** 시간이에요. 1인 사업자에게 가장 비싼 건 시간이에요. 매주 30분짜리 일 하나만 자동화해도 1년이면 26시간이 생겨요.

## 📁 들어 있는 파일
- `졸업작품_기획서.md` – 문제 · 쓰는 MCP · 검사표 결과 · 흐름도 · 안전장치 · 실패 시 대처 · 데모 체크리스트
- `예시_아이디어3개.md` – A. 유튜브 주간 리포트 / B. 공방 예약 문의 정리 / C. 독서기록 앱
- `수료_자기점검표.md` – 32강을 마치며 스스로 점검하는 표

## 🔌 연결하기
작품에 쓸 MCP는 **앞에서 연결해 본 것 중에서** 골라요. 새 MCP가 필요하면 **연결 전에 `공통/MCP_검사표.md`로 확인**하고, 결과를 기획서 3번 칸에 적어요.
- 범위는 **project**(이 키트 폴더)로. `claude mcp list`로 지금 꽂힌 것부터 정리해요 (30번 사례 6 기억!)
- 계정 로그인·권한 허용·키 발급은 **직접** 해요.
- 자동 실행이 필요하면 26번 예약 작업, 내 자료를 열어야 하면 31번 나만의 MCP를 써요.

## ⚠️ 알아 둘 것
- **작게 시작해요.** "다 되는 거" 말고 "한 번 끝까지 도는 거"가 목표예요. 범위를 줄이는 것도 실력이에요.
- 데이터는 **모두 가짜**. 진짜 손님·지인 이름, 연락처, 계좌는 쓰지 않아요.
- 보내기·게시·결제·삭제는 **초안이나 미리보기까지만**. 카톡 '나에게'는 괜찮아요.
- 데모 영상·스크린샷에 내 이메일, 계정 이름, 키가 찍히지 않았는지 확인해요.

## 🧭 기본 미션 (순서대로)
1. **고르기:** 내 생활·가게 일에서 반복되는 일 3개를 적고, 그중 하나를 고른다. 막히면 `예시_아이디어3개.md`에서 고른다
2. **기획하기:** `졸업작품_기획서.md`를 `결과/`에 복사해 1~6번을 채운다. 빈칸이 없을 때까지 만들기 시작하지 않는다
3. **단계별로 만들기:** 29번처럼 입력 → 처리 → 출력을 **하나씩** 돌리고, 단계마다 결과를 내 눈으로 확인한다
4. **이어 붙이기 + 실패 연습:** 한 번에 돌려 성공시키고, 한 단계를 일부러 실패시켜 6번 대처가 작동하는지 본다
5. **데모:** 기획서 7번 체크리스트대로 5분 데모를 해 본다 (가족·친구에게, 또는 화면 녹화)
6. **마무리:** `수료_자기점검표.md`를 채우고, 안 쓰는 MCP는 끄거나 지우고, 예약 작업은 멈춘다

## 🔥 도전 미션
- 작품을 26번 예약 작업으로 **일주일** 돌리고 점검 기록 남기기 (사용량도 기록)
- 다른 사람이 따라 할 수 있게 작품 사용 설명서 `결과/사용설명서.md` 쓰기
- 16번 깃허브에 올리기 (커밋 전 `git status`로 `.env`·키·개인정보 없는지 확인)
