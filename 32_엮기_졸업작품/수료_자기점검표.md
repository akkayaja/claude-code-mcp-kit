## 2. 연결해서 쓰기 (05~27)
| 할 수 있나요? | ○△✕ |
|---|---|
| 웹 MCP로 자료를 찾고 **원본과 숫자를 대조**한다 | |
| 노션·시트·캘린더 등은 **연습 공간에서만** 쓴다 | |
| 메일·메시지는 **초안까지만** 만들고 보내기는 내가 결정한다 | |
| 데이터베이스에 표를 만들고 한국어로 질문한다 (24) | |
| 웹페이지를 배포하고 되돌리는 법을 안다 (25) | |

| 오류 기록을 읽고 원인을 찾아 고친다 (27) | |
