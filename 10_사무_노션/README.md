# 10. 노션

> **얻는 능력:** 흩어진 메모를 Claude에게 주면 **노션 데이터베이스로 정리**해 받는 능력

**왜 배우나요?** 할 일을 여기저기 적어 두면 마감을 놓쳐요. 노션 표(데이터베이스)에 넣으면 마감일 순으로 정렬도 되고 필터도 돼요. 그런데 옮겨 적는 게 귀찮죠. 그 옮겨 적기를 Claude가 맡아요. 비유하면 **노션 MCP는 Claude에게 준 노션 열쇠**예요.

## 📁 들어 있는 파일
- `할일_원본.md` – 날짜 형식이 제각각인 가짜 할 일 메모 15줄
- `DB_구조.md` – 만들 데이터베이스의 속성(열)과 날짜 바꾸는 규칙

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 확인해요.

노션 MCP가 이미 연결돼 있는지 터미널에서 직접 확인해 보세요. (01강 도전 미션 때 연결했다면 ✔로 나와요.)
```bash
claude mcp get notion
```
→ 노션 MCP가 어디에 연결돼 있고 어떤 범위(scope)인지 나와요. ✔ 연결됨이면 그대로 써요.

만약 없다면, 이 키트 폴더에서 아래 명령으로 **이 폴더에서만** 쓰이게 추가해요.
```bash
claude mcp add --transport http --scope project notion https://mcp.notion.com/mcp
```
→ `--transport http`: 인터넷 주소로 연결 / `--scope project`: 이 폴더에서만 / 마지막은 노션 공식 주소예요.
그다음 Claude Code에서 `/mcp` → notion 선택 → 브라우저에서 노션 로그인과 **권한 허용은 내가 직접** 해요.
(공식 안내: https://developers.notion.com/docs/mcp , https://code.claude.com/docs/en/mcp)

**연습 공간 만들기 (직접):** 노션에서 새 페이지를 만들고 제목을 **`MCP 연습`** 으로 지어요. 오늘은 이 페이지 안에서만 작업해요.

## ⚠️ 알아 둘 것
- 노션 MCP는 내 노션 **전체**를 볼 수 있어요. 그래서 말할 때 항상 "`MCP 연습` 페이지 안에서만"이라고 붙여요.
- 삭제나 공유 설정 변경은 시키지 않아요. 지우고 싶으면 노션에서 내가 직접 지워요.
- Claude가 만든 결과는 꼭 노션 화면에서 눈으로 확인해요. "만들었어요"라는 말만 믿지 않기!

## 🧭 기본 미션 (순서대로)
1. `할일_원본.md`를 직접 읽고, 마감이 가장 급한 3개를 **내 손으로** 먼저 적어 둔다 (나중에 비교용)
2. 노션에 `MCP 연습` 페이지를 만들고, Claude에게 그 안에 `DB_구조.md`대로 **할 일 (연습)** 데이터베이스를 만들게 한다
3. `할일_원본.md`의 15줄을 데이터베이스에 넣게 한다 → 노션에서 **15개인지, 마감일 빈 칸이 2개인지** 직접 센다
4. 날짜가 애매한 줄("다음주 금요일", "12월 10일 전에")이 규칙대로 들어갔는지 확인한다
5. Claude에게 **마감일 순 요약**(이번 주 / 다음 주 / 그 뒤 / 마감 없음)을 받아 1번의 내 답과 비교한다
6. 결과 요약을 `결과/할일_요약.md`로 저장하게 한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 노션 데이터베이스에 "이번 주" 보기(view)를 만들 수 있는지 Claude에게 물어보고, 안 되면 내가 직접 만들기
- 2~3개를 "완료"로 바꾸게 한 뒤, 남은 할 일만 다시 요약받기 (15번 카톡 강의에서 이 요약을 나에게 보내요)

## 💬 Claude Code에 이렇게 말해 보세요
막히면 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 건 "이게 무슨 뜻이야?"라고 꼭 물어보세요.**

```
노션에서 'MCP 연습' 페이지를 찾아 줘. 그 페이지 안에서만 작업할 거야. 다른 페이지는 읽거나 고치지 마.
```
```
DB_구조.md를 읽고, 'MCP 연습' 페이지 안에 '할 일 (연습)' 데이터베이스를 만들어 줘. 만들기 전에 어떤 속성을 만들지 먼저 보여 줘.
```
```
할일_원본.md의 15줄을 그 데이터베이스에 넣어 줘. 날짜는 DB_구조.md 규칙대로 바꾸고, 애매했던 줄은 따로 알려 줘.
```
```
데이터베이스를 마감일 순으로 읽어서 이번 주 / 다음 주 / 그 뒤 / 마감 없음으로 나눠 요약해 줘.
```
