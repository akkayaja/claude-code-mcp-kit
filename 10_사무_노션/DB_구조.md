# 할 일 데이터베이스 구조

Claude에게 이 구조대로 노션 데이터베이스를 만들어 달라고 해요.
데이터베이스 이름: **할 일 (연습)** — 반드시 `MCP 연습` 페이지 **안에** 만들어요.

| 속성 이름 | 종류 | 들어갈 값 | 설명 |
|---|---|---|---|
| 할 일 | 제목(Title) | 짧은 문장 | 무엇을 하는지. 메모의 군더더기는 빼고 깔끔하게 |
| 마감일 | 날짜(Date) | 2026-12-04 형식 | 마감이 없으면 비워 둬요 |
| 분류 | 선택(Select) | 생활 / 공부 / 건강 / 가족 / 정리 | 하나만 골라요 |
| 중요도 | 선택(Select) | 높음 / 보통 / 낮음 | 메모에 "중요", "급함", "!!!"가 있으면 높음 |
| 상태 | 선택(Select) | 할 일 / 하는 중 / 완료 | 처음엔 모두 "할 일" |
| 원래 메모 | 텍스트(Text) | 원본 줄 그대로 | 나중에 Claude가 잘 옮겼는지 비교하려고 남겨요 |

## 날짜 바꾸는 규칙
- 기준일은 **2026-12-01 (화)** 이에요.
- "12/4", "12-06", "12.15", "12월 10일" → 모두 2026년 12월로 맞춰요.
- "다음주 금요일" → 2026-12-11
- "이번 주말" → 2026-12-06 (메모에 날짜가 같이 있으면 그 날짜를 따라요)
- "이번 달 안에" → 2026-12-31
- "12월 10일 전에" → 2026-12-09 (전날까지 끝내야 하니까)
- "언제든", "마감 없음" → 비워 둬요

## 검증 포인트 (직접 세어 보세요)
- 원본 메모는 **15줄**이에요. 데이터베이스에도 15개가 있어야 해요.
- 마감일이 비어 있는 건 **2개**예요.
