# 26. 정해진 시간에 자동 실행 (예약 작업)

> **얻는 능력:** "매일 아침 8시에 이거 해 줘"를 **Claude에게 맡겨 두는** 능력

**왜 배우나요?** 혼자 가게를 꾸리면 아침마다 확인할 게 많아요. 예약 작업은 **알람 시계 달린 비서**예요. 정한 시각이 되면 Claude가 스스로 일어나 정보를 모아 카톡으로 보내 줘요.

## 📁 들어 있는 파일
- `브리핑_양식.md` – 모을 정보, 결과 모양, 예약 작업에 붙여 넣을 지시문, 점검 기록표

## 🔌 연결하기
새로 꽂는 MCP는 없어요. 앞에서 연결한 **KOSIS(08) · YouTube(23) · 노션(10) · 카카오톡(15)**을 써요. 혹시 새로 연결한다면 **연결 전에 `공통/MCP_검사표.md`로 확인**해요.

예약하는 방법은 두 가지예요. 이번 강의는 **A**로 해요.

| | A. 데스크톱 앱 예약 작업 | B. `claude -p` + macOS 예약 (도전) |
|---|---|---|
| 어디서 | Claude 데스크톱 앱 **Code 탭 → Scheduled** | 터미널 명령 + cron/launchd |
| 조건 | 앱이 켜져 있고 컴퓨터가 깨어 있어야 해요 | 컴퓨터가 깨어 있어야 해요 |
| 장점 | 실행 기록(History), 일시정지 버튼, 권한 관리가 화면에 있어요 | 앱 없이 돌아가요 |

**(직접)** A 만들기: Code 탭 → **Scheduled** → **New task** → 이름 `morning-briefing` → 지시문 붙여 넣기 → **Only on this computer** 켜기 → 폴더는 이 키트 폴더 → **Create**. 만든 뒤 연필(Edit)에서 일정을 **Manual(수동)**로 바꿔 둬요. 화면 모양이 다르면(예: 예전 이름 **Routines**) 공식 문서에서 최신 방법을 확인해요.
> 공식 문서: https://code.claude.com/docs/en/desktop-scheduled-tasks · `claude -p`: https://code.claude.com/docs/en/headless

## ⚠️ 알아 둘 것
- **예약 작업도 사용량을 써요.** 한 번 실행 = 대화 한 번. 매시간 돌리면 금방 한도가 차요. 이번 강의는 **하루 1번**만.
- **끄는 법을 먼저 알고 켜요.** 작업 상세 화면의 **Active/Paused** 토글로 멈추고, **Delete**로 지워요. 지워도 `~/.claude/scheduled-tasks/작업이름/` 폴더는 남으니 직접 지워요.
- 컴퓨터가 잠들어 있으면 그 회차는 **건너뛰고**, 깨어나면 밀린 것 **1번만** 늦게 실행돼요. (그래서 양식에 "늦은 브리핑" 규칙이 있어요)
- 보내기는 **카톡 '나에게'만.** 다른 사람에게 보내는 작업은 예약하지 않아요.
- 실행 중 권한 질문이 뜨면 거기서 **멈춰서 기다려요.** 처음에 **Run now**로 한 번 돌리며 필요한 권한만 허용해 둬요.

## 🧭 기본 미션 (순서대로)
1. `브리핑_양식.md`를 `결과/`에 복사해 ❓ 칸을 채운다
2. **손으로 먼저 실행:** 지금 대화창에 지시문을 붙여 넣어 한 번 돌려 본다 → 카톡이 왔는지, `결과/브리핑_날짜.md`가 생겼는지 확인하고, 숫자 하나를 KOSIS 사이트에서 직접 맞춰 본다
3. 데스크톱 앱에서 `morning-briefing` 작업을 만들어 **Manual**로 두고 **Run now** → 뜨는 권한 질문을 읽고 필요한 것만 허용
4. 잘 되면 **Edit**에서 일정을 **Weekdays(평일) 08:00**으로 바꾼다
5. 다음 날 아침 **History(실행 기록)**를 열어 실행됐는지, 몇 분 걸렸는지, 건너뛴 회차가 있는지 보고 양식의 점검 기록표에 적는다
6. 끄기 연습: **Paused**로 바꿔 멈춘 걸 확인 → 강의가 끝나면 쓸지 말지 정해서 **Delete**까지 해 본다

## 🔥 도전 미션
