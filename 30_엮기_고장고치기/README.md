# 30. 고장 고치기 (MCP 진단)

> **얻는 능력:** MCP가 안 될 때 당황하지 않고 **증상 → 검사 → 원인 → 해결** 순서로 스스로 고치는 능력

**왜 배우나요?** 혼자 일하면 고쳐 줄 사람이 없어요. MCP 고장은 대부분 **6가지 유형** 중 하나예요: 글자 실수, 경로 실수, 열쇠 이름 실수, 범위 착각, 출입증 만료, 너무 많이 꽂음. 오늘은 **MCP 의사**가 되어 6명의 환자를 진료해요.

## 📁 들어 있는 파일
- `고장난_설정/` – 고장 난 사례 6개
  - `1_문법오류/.mcp.json` · `2_명령경로/.mcp.json` · `3_환경변수/.mcp.json` (+ `.env.example`)
  - `4_범위/시나리오.md` · `5_토큰만료/시나리오.md` · `6_도구과다/시나리오.md` (터미널 화면을 글로 옮긴 것)
- `증상카드.md` – 사례별 증상·힌트, 검사 도구 표, 내 진단을 적는 칸
- `정답_원인과해결.md` – 채점용. 6장 다 적을 때까지 열지 않아요

> 💡 `.mcp.json`, `.env.example`처럼 **점(.)으로 시작하는 파일**은 Finder에서 숨겨져 보여요. `Cmd + Shift + .`을 누르면 보여요.

## 🔌 연결하기
새 MCP를 꽂지 않아요. 대신 **진료실**을 써요: 고장 난 설정 파일 **하나만** 꽂고 Claude를 켜는 방법이에요. 내 원래 MCP 설정은 건드리지 않아요.
```bash
claude --strict-mcp-config --mcp-config 30_엮기_고장고치기/결과/고장난_설정/2_명령경로/.mcp.json
```
- `--mcp-config 파일` : 이 파일에 적힌 MCP만 불러와요
- `--strict-mcp-config` : 평소에 꽂혀 있던 다른 MCP는 **이번만 빼고** 켜요
- 자세한 기록이 필요하면 앞에 `--debug=mcp`를 더해요 (MCP 관련 기록만 보기). 기록이 길면 `--debug-file 30_엮기_고장고치기/결과/debug.log`로 파일에 저장해요

사례 2, 3은 실행하면 공식 메모리 서버·Firecrawl 패키지를 잠깐 내려받아요. 둘 다 앞 강의(07, 28)에서 **`공통/MCP_검사표.md`로 확인**한 것이에요.
> 공식 문서: https://code.claude.com/docs/en/mcp · CLI 옵션: https://code.claude.com/docs/en/cli-reference

## ⚠️ 알아 둘 것
- 원본 `고장난_설정/`은 그대로 두고 `결과/`에 복사해서 고쳐요.
- 사례 3에는 **진짜 키를 넣지 않아요.** 가짜 값으로 "이름표가 맞는지"만 확인해요.
- 디버그 기록에는 내 컴퓨터 경로 같은 정보가 섞여요. 커밋하거나 남에게 보낼 땐 먼저 훑어봐요.

## 🧭 기본 미션 (순서대로)
1. 복사하기: `mkdir -p 30_엮기_고장고치기/결과 && cp -R 30_엮기_고장고치기/고장난_설정 30_엮기_고장고치기/결과/`
2. **사례 1~3 (파일 환자):** 파일을 **먼저 눈으로** 읽고 의심 가는 곳에 표시 → `python3 -m json.tool`, `which npx`, 진료실 명령 + `/mcp`로 검사 → `증상카드.md`에 진단 적기
3. 사례 1~3을 `결과/` 쪽에서 고치고, 진료실 명령으로 다시 켜서 `/mcp`에 **✔ 연결됨**이 뜨는지 확인한다 (사례 3은 가짜 키라 연결 뒤 사용은 실패해도 OK — 경고가 사라지면 통과)
4. **사례 4~6 (이야기 환자):** 시나리오를 읽고 진단·처방을 적는다. 사례 4는 내 컴퓨터에서 `claude mcp get 이름`으로 **실제 범위**를 확인해 보는 것까지
5. 다 적었으면 `정답_원인과해결.md`로 채점하고, 틀린 것은 "왜 그렇게 생각했는지"를 Claude와 이야기한다
6. **내 진료 순서표**를 `결과/진료순서.md`로 만든다 (예: ① `claude mcp list` → ② `/mcp` → ③ 문법 검사 → ④ 디버그 기록)

## 🔥 도전 미션
- 내 실제 MCP 목록에서 **안 쓰는 것**을 찾아 끄거나 지우기 (지우기 전 목록을 `결과/`에 백업)
- 친구에게 낼 **7번째 고장 문제**를 직접 만들기 (예: `"type"` 없이 `"url"`만 적은 원격 MCP)
