# 시나리오 4: "분명히 추가했는데 목록에 없어요"

어제 저녁, 바탕화면에서 터미널을 열고 아래처럼 했어요.

```
~/Desktop $ claude mcp add --transport http context7 https://mcp.context7.com/mcp
Added HTTP MCP server context7 with URL: https://mcp.context7.com/mcp to local config
```

오늘 아침, 키트 폴더에서 확인했더니…

```
~/클로드코드 실습1/클로드코드_MCP키트 $ claude mcp list
Checking MCP server health...

notion: https://mcp.notion.com/mcp (HTTP) - ✔ Connected
```

context7이 없어요! 다시 바탕화면에 가서 `claude mcp list`를 하면 거기엔 있어요.
