# 시나리오 5: "어제까지 잘 되던 노션이 갑자기 안 돼요"

한 달 넘게 잘 쓰던 노션 MCP. 오늘 아침 브리핑 예약 작업(26번)이 실패했어요.

```
$ claude mcp list
Checking MCP server health...

notion: https://mcp.notion.com/mcp (HTTP) - ⚠ Needs authentication
kakao: ... - ✔ Connected
```

예약 작업 실행 기록에는 이렇게 적혀 있어요.

```
⚠️ 못 가져온 것: 노션 할 일 (401 Unauthorized)
```

어제 한 일: 노션 웹에서 **설정 → 연결(Connections)** 화면을 정리하다가 "모르는 연결 몇 개"를 끊었어요. 비밀번호도 바꿨고요.

## 생각해 볼 것
- `401 Unauthorized` = "출입증이 없거나 만료됐어요". 설정 파일이 고장 난 걸까요, 출입증이 무효가 된 걸까요?
- 설정 파일을 고쳐야 할까요, 아니면 다시 로그인해야 할까요?
- 앞으로 예약 작업이 이런 일로 조용히 실패하지 않게 하려면?
