# 정답: 원인과 해결

> 6장 모두 진단을 적은 뒤에 **채점할 때만** 열어요.

## 1. JSON 문법 오류
- **원인 ①:** `"MEMORY_FILE_PATH": "/tmp/연습_memory.jsonl",` — 마지막 항목 뒤에 **쉼표(,)**가 남았어요. JSON은 마지막 쉼표를 허용하지 않아요.
- **원인 ②:** memory 블록을 닫는 `}` 뒤에 **쉼표가 빠졌어요.** `} "context7"` → `}, "context7"`
- **찾는 법:** `python3 -m json.tool 1_문법오류/.mcp.json` → 틀린 줄 번호를 알려 줘요.
- **교훈:** 설정 파일 하나가 깨지면 **그 안의 MCP가 전부** 안 보여요. 고친 뒤 반드시 문법 검사.

## 2. 명령 경로가 틀림
- **원인:** `/opt/homebrew/bin/npx`는 다른 종류 맥(Homebrew로 설치한 경우)의 경로예요. 이 컴퓨터의 npx는 `/usr/local/bin/npx`예요.
- **해결:** `"command": "npx"`처럼 **이름만** 쓰거나, `which npx`로 나온 경로를 그대로 써요.
- **찾는 법:** `claude --debug=mcp`로 켜면 "명령을 찾을 수 없다(ENOENT)" 같은 기록이 보여요.
- **교훈:** 남의 설정을 복사할 땐 **경로**를 내 컴퓨터 것으로 바꿔요.

## 3. 환경변수 이름 불일치 + .env를 안 읽음
- **원인 ①:** 설정은 `${FIRECRAWL_API_KEY}`를 찾는데, `.env`에는 `FIRECRAWL_KEY`라고 적혀 있어요. 이름표가 달라요.
- **원인 ②:** Claude Code는 `.mcp.json`의 `${...}`를 **터미널(셸)의 환경변수**에서 채워요. `.env` 파일을 자동으로 읽지는 않아요. 값이 없으면 `${FIRECRAWL_API_KEY}` 글자가 그대로 들어가고 `claude mcp list`가 경고를 보여 줘요.
- **해결:** `.env`의 이름을 `FIRECRAWL_API_KEY`로 맞추고, Claude를 켜기 전에 터미널에 불러와요: `set -a; source .env; set +a` (= ".env의 값을 이 터미널의 환경변수로 올려라"). 또는 `${FIRECRAWL_API_KEY:-}`처럼 기본값을 둬서 경고 대신 빈 값으로 시작하게 할 수도 있어요.
- **교훈:** 키는 `.env`에만, 설정 파일엔 `${이름}`만. 그리고 **이름표를 글자 하나까지** 맞춰요.

## 4. 범위(scope) 착각
- **원인:** `--scope`를 안 쓰면 기본값은 **local** = "그 명령을 실행한 폴더(프로젝트)에서만, 나만". 바탕화면에서 추가했으니 바탕화면에서만 보여요.
- **해결:** 바탕화면에서 `claude mcp remove context7 -s local` → 키트 폴더로 이동 → `claude mcp add --scope project --transport http context7 https://mcp.context7.com/mcp`
- **찾는 법:** `claude mcp get context7`(바탕화면에서)로 범위를 확인해요.
- **교훈:** 추가할 땐 **어느 폴더에 있는지** + **`--scope`**를 항상 확인. local(이 폴더·나만) / project(이 폴더·`.mcp.json`으로 공유) / user(내 컴퓨터 전체).

## 5. 출입증(토큰) 만료·취소
- **원인:** 노션 쪽에서 연결을 끊고 비밀번호를 바꿔서 **OAuth 출입증이 무효**가 됐어요. 설정 파일은 멀쩡해요.
- **해결:** `/mcp` → notion → **Authenticate**(다시 로그인, **직접**). 연결 권한 목록을 다시 읽고 허용.
- **교훈:** `401`, `Needs authentication` = 설정이 아니라 **로그인 문제**. 예약 작업은 사람이 없어서 다시 로그인할 수 없으니, 브리핑에 "⚠️ 못 가져온 것" 칸을 두는 게 중요해요(26번).

## 6. MCP·도구가 너무 많음
- **원인:** 22개가 꽂혀 있어 시작할 때 모두 연결을 시도하고, ✘인 blender는 연결될 때까지 기다리게 해요. 비슷한 일을 하는 도구(노션·옵시디언)가 많아 Claude가 헷갈려요.
- **해결:** 지금 강의에 필요한 것만 남기기. 잠깐 안 쓸 건 `/mcp`에서 **끄기(disable)**, 다시 안 쓸 건 `claude mcp remove 이름 -s 범위`. 요청할 때 "**노션 MCP로**"처럼 이름을 콕 집어 말하기.
- **참고:** Claude Code는 MCP 도구 설명을 필요할 때만 불러오는 **도구 검색(tool search)**이 기본으로 켜져 있어서, 예전보다는 덜 느려요. 그래도 연결 시도·헷갈림은 그대로예요.
- **교훈:** 콘센트가 많다고 좋은 게 아니에요. **강의마다 꽂고, 끝나면 뽑기.**
