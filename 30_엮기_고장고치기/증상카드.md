## 검사 도구 (청진기 세트)
| 도구 | 어디서 | 무엇을 보여 주나요 |
|---|---|---|
| `claude --strict-mcp-config --mcp-config 파일` | 터미널 | **그 설정 파일 하나만** 꽂고 Claude 켜기 (진료실 역할) |
| `claude mcp list` | 터미널 | 지금 폴더에서 보이는 MCP와 연결 상태 (✔ / ✘ / ⚠) |
| `claude mcp get 이름` | 터미널 | 그 MCP의 설정과 **범위(scope)** |
| `/mcp` | Claude 대화창 | 연결 상태, 도구 목록, 로그인(Authenticate), 끄기 |
| `claude --debug=mcp` | 터미널 | MCP 연결 과정을 자세히 기록 (MCP 관련 기록만 골라 보기) |
| `claude --debug-file 결과/debug.log` | 터미널 | 자세한 기록을 파일로 저장 |
| `python3 -m json.tool 파일` | 터미널 | JSON 문법 검사 (틀린 줄을 알려 줘요) |
| `which 명령이름` | 터미널 | 그 프로그램이 내 컴퓨터 어디에 있는지 |
