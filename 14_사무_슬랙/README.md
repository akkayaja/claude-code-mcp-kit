# 14. 팀 메신저

> **얻는 능력:** 길게 쌓인 채널 대화를 Claude가 **결정 사항·할 일로 요약**하고, 내 답장 **초안**까지 써 주는 능력

**왜 배우나요?** 단체 대화방은 잠깐만 안 봐도 수십 개가 쌓여요. "그래서 뭐가 정해졌고, 내가 할 일은 뭐지?"만 알면 되는데 말이죠. Claude가 채널을 읽고 정리해 주면 따라잡는 시간이 확 줄어요. 비유하면 **회의록 담당자**예요.

## 📁 들어 있는 파일
- `대화_원본.md` – 가상의 러닝 모임 '달빛크루' 운영진의 가짜 대화 25개

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 확인해요.

**1) 연습용 워크스페이스 만들기 (직접)**
- 회사·학교 슬랙이 **아니라**, 나 혼자 쓰는 **무료 개인 워크스페이스**를 새로 만들어요 (https://slack.com/get-started).
- 채널 **`#mcp-연습`** 을 만들어요. 가입·로그인은 내가 직접 해요.
- 내가 만든 워크스페이스라 내가 관리자예요. 그래서 MCP 연결 승인도 내가 할 수 있어요.

**2) Slack 공식 MCP 연결 (둘 중 하나)**
- **데스크톱 앱 커넥터 (쉬움):** 사이드바 Customize → Connectors → `+` → **Slack** 추가 → 슬랙 로그인·권한 허용(내가 직접). 이때 **연습 워크스페이스**를 골랐는지 꼭 확인해요.
- **Claude Code 플러그인:** 터미널에서 아래를 직접 실행해요.
  ```bash
  claude plugin install slack
  ```
  → 슬랙이 공식으로 안내하는 플러그인을 설치해요. 플러그인이 `https://mcp.slack.com/mcp`(슬랙 공식 주소)에 연결해요. 설치 후 Claude Code에서 `/mcp` → slack → 로그인은 내가 직접 해요.
  플러그인은 보통 내 컴퓨터 전체(user 범위)에 깔려요. 다 쓰면 `/plugin`에서 끄거나 지워요.

공식 안내: https://docs.slack.dev/ai/slack-mcp-server/connect-to-claude
⚠️ **무료 워크스페이스에서 공식 MCP가 되는지는 공식 문서에 분명히 적혀 있지 않아요.** 공식 문서에서 최신 방법을 확인해요. 안 되면 비공식 MCP(로그인 쿠키·토큰을 쓰는 것)는 쓰지 말고, `대화_원본.md`를 Claude Code에서 바로 요약하는 것으로 미션 3~5를 대신해요.

## ⚠️ 알아 둘 것
- **회사 슬랙에 연결하지 않아요.** 동료의 대화는 내 것이 아니에요. 회사 규칙상 금지일 수도 있어요.
- 슬랙 MCP에는 **메시지 보내기** 도구가 있어요. 답장은 **채팅창 초안 → 내가 확인 → `#mcp-연습`에만 게시** 순서로 해요.
- 다른 채널·DM은 읽지 않게, 말할 때마다 "`#mcp-연습` 채널만"을 붙여요.

## 🧭 기본 미션 (순서대로)
1. `대화_원본.md`를 직접 읽고 **결정된 것 3개, 누가 무엇을 언제까지** 를 내가 먼저 적는다
2. 연습 워크스페이스와 `#mcp-연습` 채널을 만들고, 대화 원본을 3~4번에 나눠 붙여 넣는다
3. Claude에게 `#mcp-연습` 채널만 읽고 **결정 사항 / 할 일(담당·마감) / 아직 안 정해진 것** 으로 요약하게 한다
4. 1번 내 메모와 비교한다. 숫자 확인: 날짜·시간, 코스 3개, 예산 합계가 맞는지 직접 계산해 본다
5. "나연습"으로서 보낼 답장 **초안**을 채팅창에 받고, 내가 고친다
6. 확인한 답장만 `#mcp-연습`에 올리게 하고, 요약은 `결과/채널_요약.md`로 저장한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 할 일만 뽑아 마감일 순 체크리스트로 만들고, 10강처럼 노션 `MCP 연습` 페이지에 넣기
- 요약 형식을 "3줄 + 내 할 일"로 정해 두고, 15강 카톡 '나에게 보내기'와 엮을 준비하기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 건 "이게 무슨 뜻이야?"라고 꼭 물어보세요.**

```
슬랙에서 '#mcp-연습' 채널만 읽어 줘. 다른 채널과 DM은 열지 마. 메시지가 몇 개인지 먼저 알려 줘.
```
```
그 채널 대화를 '결정된 것 / 할 일(누가·무엇을·언제까지) / 아직 안 정해진 것'으로 요약해 줘. 예산 계산도 다시 확인해 줘.
```
```
내가 '나연습'이야. 폼 만들기를 맡겠다는 답장 초안을 3줄로 써 줘. 아직 슬랙에 올리지 말고 여기에만 보여 줘.
```
```
좋아, 이 문장 그대로 '#mcp-연습' 채널에만 올려 줘. 다른 곳에는 보내지 마.
```
