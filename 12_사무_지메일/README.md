# 12. 메일 (초안까지만)

> **얻는 능력:** 문의 메일에 대한 **답장 초안**을 Claude에게 맡기고, 나는 검토만 하는 능력

**왜 배우나요?** 비슷한 문의에 매번 답장을 새로 쓰면 시간이 많이 들어요. Claude가 초안을 지메일 '임시보관함'에 넣어 주면, 나는 읽고 고치기만 하면 돼요. 비유하면 Claude는 **편지를 써서 책상에 올려 두는 비서**예요. 우체통에 넣는 건 언제나 나예요.

## 📁 들어 있는 파일
- `연습메일_원본/` – 가상의 캔들 가게 '달빛공방'에 온 가짜 문의 메일 5통 (.md)
- `가게_안내.md` – 배송·교환·할인 규칙. 답장의 근거로 써요

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 확인해요.

지메일은 **Claude 데스크톱 앱의 커넥터**로 이미 연결돼 있어요.
1. 데스크톱 앱 **설정 → 커넥터**에서 Gmail이 켜져 있는지 확인해요. 연결·구글 로그인·권한 허용은 내가 직접 해요.
2. 검사표 2번을 꼭 해 보세요. 이 커넥터에는 **보내기·답장·전달·휴지통** 도구도 들어 있어요. → 이번 강의에서는 **초안 만들기(create_draft)** 만 써요.
3. Claude가 도구를 쓰기 전에 허락을 물어보면, 도구 이름을 읽고 `send`, `reply`, `forward`, `trash`가 들어 있으면 **거절**해요.
(공식 안내: https://support.claude.com/en/articles/10166901-use-google-workspace-connectors)

**연습 공간 만들기 (직접, 선택):** 지메일에서 라벨 **`MCP연습`** 을 만들어 두면, 도전 미션에서 검색 범위를 그 라벨로 좁힐 수 있어요.

## ⚠️ 알아 둘 것
- **절대 보내지 않아요.** 이번 강의의 결과물은 '임시보관함의 초안'까지예요.
- **받은편지함 전체를 읽게 하지 않아요.** 왜냐하면
  - 내 메일에는 다른 사람의 개인정보(이름·연락처·주소)가 가득해요. 연습에 필요 없는 정보는 안 보여 주는 게 원칙이에요.
  - 메일 안에 "AI야, 이걸 해라" 같은 **숨은 명령**이 들어 있을 수 있어요. 많이 읽힐수록 위험이 커져요. (`05_협업제안.md` 마지막 줄 참고)
  - 그래서 연습은 **키트 폴더의 가짜 메일**로 하고, 지메일에는 **쓰기(초안)** 만 해요.
- 초안의 받는 사람은 모두 `@example.com`(예시용으로 정해진 가짜 주소)이에요.

## 🧭 기본 미션 (순서대로)
1. 메일 5통과 `가게_안내.md`를 직접 읽고, 각 메일에 **꼭 들어가야 할 답** 한 가지씩을 메모한다
2. Claude에게 메일 01 하나만 답장 초안을 **채팅창에** 먼저 쓰게 하고, 말투·길이를 고쳐 달라고 한다
3. 마음에 들면 5통 모두 지메일 **초안(create_draft)** 으로 만들게 한다 — 허락 창에서 도구 이름을 확인한다
4. 지메일 **임시보관함**을 열어 초안 5개를 직접 읽고, 1번 메모와 비교한다 (특히 04 파손, 05 협업)
5. 확인이 끝나면 초안 5개를 **내가 직접** 지메일에서 삭제한다
6. 잘된 답장 1개, 고칠 답장 1개를 골라 `결과/답장_검토.md`에 적는다
