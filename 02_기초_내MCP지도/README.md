# 02. 내 MCP 지도

> **얻는 능력:** 내 Claude에 **지금 어떤 MCP가 꽂혀 있고, 각각 무엇을 할 수 있는지** 한 장의 표로 정리하는 능력

**왜 배우나요?** 집에 콘센트가 몇 개인지, 어디에 다리미가 꽂혀 있는지 모르면 불이 나도 끌 수가 없어요. MCP도 마찬가지예요. 내가 연결해 둔 것 중에 **메일을 보내거나 파일을 지울 수 있는 것**이 있는지 먼저 알아야 안전하게 쓸 수 있어요.

## 📁 들어 있는 파일
- `MCP지도_양식.md` – 빈 지도 표. 복사해서 `결과/내_MCP지도.md`로 채워요

## 🔌 연결하기
새로 연결하지 않아요. **이미 연결된 것을 확인만** 해요. 두 군데를 봐야 해요.
1. **Claude Code 쪽:** 터미널에서 이 키트 폴더로 이동한 뒤
   ```bash
   claude mcp list
   ```
   → Claude Code에 등록된 MCP 이름과 연결 상태(✔ 연결됨 / ✘ 실패)가 나와요.
   ```bash
   claude mcp get 이름
   ```
   → 그 MCP가 어떤 범위(local/project/user)인지, 무엇을 실행하는지 보여 줘요.
2. **데스크톱 앱 쪽:** 설정 → **커넥터** 화면. 여기서 연결한 것(예: 지메일, 구글 드라이브, 통계청)은 `claude mcp list`에 안 나올 수 있어요.
3. **도구 목록:** Claude Code 대화창에서 `/mcp` → MCP 하나를 고르면 그 MCP의 도구 이름이 쭉 나와요.

## ⚠️ 알아 둘 것
- 이번 강의는 **보기만** 해요. 도구를 실제로 실행하지 않아요.
- 도구 이름에 `send`, `delete`, `trash`, `share`, `create`, `update`, `deploy`, `pay`가 들어 있으면 **바깥 세상을 바꾸는 도구**예요. 빨간색으로 표시해 두세요.
- 지도에 계정 이메일·연결 주소 안의 비밀 값은 적지 않아요. MCP 이름과 도구 이름만 적어요.

## 🧭 기본 미션 (순서대로)
1. **추측 먼저:** 내 Claude에 MCP가 몇 개 연결돼 있을지 숫자로 짐작해 적는다
2. `claude mcp list` 결과와 데스크톱 앱 커넥터 화면을 보고, MCP 이름을 **모두** `결과/내_MCP지도.md` 1번 표에 적는다 (어디서 봤는지 칸도 채우기)
3. MCP마다 `/mcp`(또는 Claude에게 물어서) 도구 목록을 보고, 도구를 **읽기 / 쓰기 / 보내기 / 삭제** 4가지로 나눠 2번 표에 적는다
4. 위험도를 매긴다: 읽기만 = 🟢, 쓰기 있음 = 🟡, 보내기·삭제·결제·공개 있음 = 🔴
5. 🔴 MCP마다 "이 도구는 초안까지만 / 내가 확인한 뒤에만" 같은 **내 사용 규칙** 한 줄을 쓴다
6. 지금 안 쓰는 MCP 하나를 골라 끌지 말지 정한다 (끄는 건 03번에서 연습해요)

## 🔥 도전 미션
- 지도를 Claude에게 보여 주고 "내가 놓친 위험한 도구가 있는지" 다시 점검받기
- 지도를 머메이드(mermaid) 그림으로 그려 달라고 해서 한눈에 보기

## 💬 Claude Code에 이렇게 말해 보세요
```
지금 이 대화에서 쓸 수 있는 MCP 서버와 도구를 전부 표로 정리해 줘. 도구마다 읽기/쓰기/보내기/삭제 중 무엇인지 분류해 줘. 도구는 실행하지 말고 이름만 봐 줘.
```
```
claude mcp list 결과에 있는 것과, 데스크톱 앱 커넥터로만 연결된 것을 나눠서 보여 줘.
```
```
이 표에서 메일·메시지 보내기, 삭제, 결제, 공개 게시를 할 수 있는 도구만 골라 줘.
```
