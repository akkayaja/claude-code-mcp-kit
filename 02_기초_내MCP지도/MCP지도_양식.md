## 2. MCP별 도구와 위험도
> 읽기 = 보기만 함 / 쓰기 = 만들거나 고침 / 보내기 = 다른 사람에게 감 / 삭제 = 지우거나 휴지통
> 위험도: 🟢 읽기만 · 🟡 쓰기 있음 · 🔴 보내기·삭제·결제·공개 있음

| MCP 이름 | 읽기 도구 (예시 2~3개) | 쓰기 도구 | 보내기 도구 | 삭제 도구 | 위험도 |
