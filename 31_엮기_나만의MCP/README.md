# 31. 나만의 MCP 만들기 (파이썬)

> **얻는 능력:** 남이 만든 콘센트를 꽂는 데서 끝나지 않고, **내 자료를 Claude에게 여는 콘센트를 직접 만드는** 능력

**왜 배우나요?** 내 가게의 주문 파일, 내 학습일지, 내 레시피 모음… 이런 건 어떤 회사도 MCP를 만들어 주지 않아요. 파이썬 파일 하나로 **나만의 MCP 서버**를 만들 수 있어요. 오늘은 내 학습일지 폴더를 여는 콘센트를 만들어요.

## 📁 들어 있는 파일
- `요구사항.md` – 만들 도구 3개(오늘_기록_목록 · 키워드로_찾기 · 진도_요약)와 규칙, 시험 질문
- `샘플_학습일지/` – 가짜 학습일지 6개. 내 진짜 일지 대신 이걸로 먼저 만들어요
- `정답_예시_서버.py` – 비교용 정답. 직접 만들어 본 뒤에만 열어요

## 🔌 연결하기
**연결 전에 `공통/MCP_검사표.md`로 확인**해요. 이번엔 "내가 만든 것"이니 출처는 나, 권한은 **읽기 전용**인지 확인해요.

1. **준비 (파이썬 3.10 이상 필요):** 이 맥의 기본 `python3`는 3.9라서 MCP 파이썬 SDK가 설치되지 않아요. 이미 깔려 있는 `uv`로 3.12 가상환경을 만들어요. (키트 폴더에서)
   ```bash
   uv venv --python 3.12 31_엮기_나만의MCP/.venv
   uv pip install --python 31_엮기_나만의MCP/.venv/bin/python "mcp[cli]"
   ```
   - `uv venv` : 이 강의 전용 파이썬 방(가상환경)을 만들어요 · `"mcp[cli]"` : 공식 MCP 파이썬 SDK + 시험 도구
   - `.venv` 폴더는 커밋하지 않아요 (`.gitignore`에 `.venv/` 확인)
2. 서버 파일은 `31_엮기_나만의MCP/결과/study_log_server.py`로 만들어요 (미션 2~3)
3. Claude Code에 **project 범위**로 꽂아요:
   ```bash
   claude mcp add --scope project --transport stdio study-log -- "$PWD/31_엮기_나만의MCP/.venv/bin/python" "$PWD/31_엮기_나만의MCP/결과/study_log_server.py"
   ```
   → `--transport stdio` : 인터넷이 아니라 **내 컴퓨터에서 프로그램을 켜서** 대화하는 방식이에요
4. `claude` 다시 실행 → 허용 → `/mcp`에서 `study-log` ✔ 와 도구 3개 확인

> 공식 문서: https://github.com/modelcontextprotocol/python-sdk · https://code.claude.com/docs/en/mcp

## ⚠️ 알아 둘 것
- 지금 SDK는 **2.x**예요. 인터넷 예제의 `from mcp.server.fastmcp import FastMCP`는 1.x 방식이라 오류가 나요. 2.x는 `from mcp.server import MCPServer`예요. 헷갈리면 Claude에게 "공식 문서 최신 방법"으로 확인해 달라고 해요.
- **도구 이름은 영어**(`search_logs`), 한국어는 title과 설명에 넣어요. 이유는 `요구사항.md`에 있어요.
- 서버는 **읽기 전용**으로 만들어요. 파일을 지우는 도구를 만들면 Claude가 실수로 지울 수도 있어요.
- stdio 서버에서는 `print()`로 화면에 찍으면 **대화 통로가 막혀** 고장 나요. 확인용 출력은 하지 않아요.

1. `요구사항.md`를 읽고 ❓를 채운다. 샘플 일지 2개를 열어 **날짜 줄과 MCP 줄이 어떻게 생겼는지** 직접 본다
2. Claude와 함께 **도구 1개(진도_요약)만** 있는 서버를 만든다. 줄마다 무슨 뜻인지 설명을 듣는다
3. 나머지 도구 2개를 더한다
4. **MCP Inspector**(시험대)로 꽂기 전에 시험한다 → 브라우저에서 도구를 하나씩 눌러 `요구사항.md` 시험 질문의 예상 답과 비교
   ```bash
   npx @modelcontextprotocol/inspector "31_엮기_나만의MCP/.venv/bin/python" "31_엮기_나만의MCP/결과/study_log_server.py"
   ```
5. Claude Code에 꽂고(연결하기 3번) "진도 요약해 줘", "KOSIS 기록 찾아 줘"라고 한국어로 물어 **내 서버 도구가 불리는지** 확인한다
6. `정답_예시_서버.py`와 비교하고, 다른 점 1개를 골라 내 서버를 개선한다
