# 요구사항: 학습일지 MCP 서버 (`study-log`)

> 내가 만드는 **첫 콘센트**예요. 꽂으면 Claude가 내 학습일지 폴더를 **읽을 수** 있어요.
> ❓ 칸은 내 생각으로 채워요.

## 한 줄 목표
"내 학습일지에서 ○○ 찾아 줘", "진도 어디까지야?"라고 물으면 Claude가 **내 기록**을 근거로 답하게 한다.

## 도구 3개
| 하는 일 (title, 한국어) | 도구 이름 (영어) | 입력 | 출력 |
|---|---|---|---|
| 오늘_기록_목록 | `list_logs_by_date` | 날짜(비우면 오늘) | 그날 기록 파일 이름들. 없으면 최근 3개 |
| 키워드로_찾기 | `search_logs` | 키워드 | `파일이름:줄번호: 그 줄` 목록 (최대 20줄) |
| 진도_요약 | `progress_summary` | (없음) | 기록한 강의 수·번호, 기간, 연결한 MCP 횟수 |

> 💡 **도구 이름은 왜 영어?** Claude에게 전달되는 도구 이름은 **영문·숫자·`_`·`-`만** 쓸 수 있어요. 한글은 **title(보여 주는 이름)**과 **설명**에 넣어요. 이름표는 영어, 안내문은 한국어!

## 일지 파일 모양 (샘플_학습일지/ 참고)
- 파일 이름: `NN_폴더이름.md` (NN = 강의 번호)
- `- **날짜:** 2026-11-10` 줄에 날짜
- `## 🔌 연결한 MCP` 아래 `- 이름` 줄들

## 지켜야 할 규칙
1. **읽기만 해요.** 파일 만들기·고치기·지우기 도구는 만들지 않아요.
2. **학습일지 폴더 밖은 못 봐요.** 경로를 입력으로 받지 않아요.
3. 폴더 위치는 코드에 박지 말고 **환경변수 `STUDY_LOG_DIR`**로 받아요. 없으면 `샘플_학습일지/`.
4. 결과가 너무 길면 잘라요 (Claude 대화 자리를 아껴요).
5. 기록이 없거나 키워드가 비면 **오류 대신 친절한 안내 문장**을 돌려줘요.
