# MCP 검사표 (설치 전에 매번)

> 04번 강의에서 이 표를 내 말로 고쳐서 완성해요. 그 전까지는 이 기본판을 써요.
> Claude에게 "이 MCP를 검사표로 같이 확인해 줘"라고 하면 돼요.

**MCP 이름:**            **검사한 날:**

## 1. 누가 만들었나요? (출처)
- [ ] 서비스 회사가 **직접** 만든 공식 MCP인가요? (예: 노션이 만든 노션 MCP)
- [ ] 공식이 아니라면, 많은 사람이 쓰고 최근까지 관리되고 있나요? (마지막 업데이트 날짜, 별 개수, 이슈 확인)
- [ ] 설치 주소가 공식 문서에 적힌 주소와 **글자 하나까지** 같나요? (비슷한 이름의 가짜 주의)

## 2. 무엇을 할 수 있나요? (권한)
- [ ] 읽기만 하나요, 쓰기·삭제도 하나요?
- [ ] 메일·메시지 **보내기**, **결제**, **공개 게시** 기능이 있나요? → 있다면 그 도구는 쓰지 않거나 확인 후에만
- [ ] 내 컴퓨터 파일 전체에 접근하나요? → 그렇다면 연습에 쓰지 않아요
- [ ] 로그인할 때 요청하는 권한 목록을 읽어 봤나요?

## 3. 어떻게 연결되나요?
- [ ] 원격(HTTP) 연결인가요, 내 컴퓨터에서 실행되는 프로그램인가요?
- [ ] 키가 필요하다면 `.env`에 넣고, 설정 파일에 키를 직접 쓰지 않았나요?
- [ ] 범위: 이 폴더에서만(project) 쓰나요, 내 컴퓨터 전체(user)에서 쓰나요?

## 4. 되돌릴 수 있나요?
- [ ] 끄는 법을 알아요 (`/mcp`에서 끄기 또는 커넥터 끄기)
- [ ] 지우는 법을 알아요 (`claude mcp remove 이름`)
- [ ] 서비스 쪽에서 권한을 취소하는 법을 알아요 (계정 설정 → 연결된 앱)
