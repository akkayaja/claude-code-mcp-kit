# 내 컴퓨터 공통 설정 (맥북·맥미니 똑같이 맞추기)

> 이 파일은 **새 컴퓨터에서 Claude Code를 같은 규칙으로 쓰기 위한 안내서**예요.
> 새 컴퓨터의 Claude에게 "공통/내컴퓨터_공통설정.md 대로 설정해 줘"라고 하면 돼요.

## 1. 커넥터 (계정에 저장, 따로 할 일 없음)
같은 Claude 계정으로 로그인하면 자동으로 있어요: 노션, Context7, 지메일, 구글 드라이브·시트·문서·슬라이드, 국가통계(KOSIS), PlayMCP(카카오톡·유튜브), 슈파베이스, 버셀 등.
→ 설정 → 커넥터에서 켜져 있는지만 확인해요.

## 2. 모든 폴더 규칙 (컴퓨터마다 따로 넣어야 함)
아래 내용을 그 컴퓨터의 `~/.claude/CLAUDE.md`에 넣어요. 파일이 이미 있으면 **기존 내용은 그대로 두고 맨 아래에 덧붙여요.**

```markdown
# 모든 폴더에 공통으로 적용하는 규칙

## 코드 짤 때 최신 문서 확인 (Context7)
- 외부 라이브러리(pandas, matplotlib, Tailwind, React 등)로 코드를 새로 쓰거나, 버전 때문으로 보이는 오류가 나면 **Context7로 최신 공식 문서를 먼저 확인**한다.
- 파이썬 기본 도구(csv, pathlib, json, os 등)는 확인하지 않아도 된다.
- 확인했으면 어느 라이브러리 문서를 참고했는지 한 줄로 알려 준다.
- Context7이 연결돼 있지 않거나 "요청이 너무 많다"고 하면, 그 사실을 알리고 기억으로 진행하되 "공식 문서 확인 안 함"이라고 밝힌다.
```

## 3. 이 키트 폴더에서만 쓰는 MCP (`.mcp.json`, 저장소에 들어 있음)
노션, Playwright, Context7이 적혀 있어요. 저장소를 받은 뒤 그 폴더에서 `claude`를 처음 켜면:
1. 폴더 신뢰 → **Yes, I trust this folder**
2. MCP 서버마다 → **Use this MCP server** (이것만 승인)
3. 노션은 `/mcp` → notion → Authenticate 로 로그인 (직접)
