# 정답_문제목록 (채점할 때만 열기)

연습사이트에는 문제가 **5개** 숨어 있어요. 찾은 개수 = 점수예요.

| # | 문제 | 어디에 | 어떻게 찾나 (DevTools MCP 도구 예) | 고치는 법 |
|---|---|---|---|---|
| 1 | **자바스크립트 오류** `TypeError: Cannot set properties of null (setting 'textContent')` | `app.js` 14줄: 없는 `#cart-count`를 찾음 | `list_console_messages` → 빨간 오류 1개. 그 뒤 "끝까지 실행됨" 로그가 **안 찍힘** | HTML에 `<span id="cart-count">`를 넣거나, 그 줄을 지우거나, 요소가 있을 때만 실행 |
| 2 | **깨진 이미지 (404)** | `index.html` 라벤더: `images/lavendar.png` (철자 틀림) | `list_network_requests` → 404 하나. 화면에 회색 빈칸 | 실제 파일 이름 `lavender.png`로 고치기 |
| 3 | **너무 큰 이미지** 약 3.5MB, 1400×1000 | `images/hero-big.png`를 320px로 줄여서 보여 줌 | `list_network_requests`에서 크기 확인, `lighthouse_audit` 또는 `performance_start_trace`에서 "이미지 크기 줄이기" 경고 | 보여 줄 크기(예: 640px 폭)로 줄이고 JPG/WebP로 저장 → 수십 KB대 |
| 4 | **휴대폰에서 가로로 넘침** | `style.css` `.event-banner { width: 860px; white-space: nowrap; }` | `resize_page`나 `emulate`로 375px 폭 → `take_screenshot`에 옆으로 밀리는 화면 | `width` 대신 `max-width: 100%`, `white-space: normal` |
| 5 | **대체 글(alt) 없음** | `index.html` 데이지 `<img src="images/daisy.png">` | `take_snapshot`에서 이름 없는 이미지, Lighthouse 접근성 항목 | `alt="노란 데이지 한 묶음"` 추가 |

## 채점 메모
- 5개 다 찾음: 🏆 / 3~4개: 좋아요, 놓친 걸 도구로 다시 찾아보기 / 2개 이하: 미션 3~5를 다시
- 1번은 화면만 보면 거의 티가 안 나요. **콘솔을 봐야** 찾을 수 있는 문제라서, 이 MCP를 쓰는 이유가 돼요.
- 3번의 "느림"은 내 컴퓨터(localhost)에서는 잘 안 느껴져요. 도구로 **크기 숫자**를 보고 판단해요.
