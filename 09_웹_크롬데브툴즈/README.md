# 09. 웹페이지 진단 (Chrome DevTools)

> **얻는 능력:** 웹페이지의 **숨은 고장(오류·깨진 그림·느린 그림·휴대폰 화면 넘침·접근성)**을 Claude와 함께 찾아내고 고치는 능력

**왜 배우나요?** 화면은 멀쩡해 보여도 뒤에서 오류가 나는 페이지가 많아요. 크롬 개발자 도구(DevTools)는 웹페이지의 **건강검진 기계**인데, 메뉴가 복잡해요. Chrome DevTools MCP를 꽂으면 Claude가 그 기계를 대신 조작하고 결과를 쉬운 말로 알려 줘요.

## 📁 들어 있는 파일
- `연습사이트/` – 가짜 동네 꽃집 "들꽃상점". **문제 5개**가 숨어 있어요
- `정답_문제목록.md` – 문제 5개와 고치는 법 (**채점 전까지 열지 않기**)

## 🔌 연결하기
Chrome DevTools MCP는 **구글 크롬 팀이 직접 만든** 공식 MCP예요. 크롬 창을 하나 띄워 검사해요. (구글 크롬이 설치돼 있어야 해요)
1. **검사표로 먼저 확인:** `공통/MCP_검사표.md` (출처: github.com/ChromeDevTools/chrome-devtools-mcp)
2. 키트 맨 위 폴더에서 직접 실행해요.
   ```bash
   claude mcp add --scope project chrome-devtools -- npx -y chrome-devtools-mcp@latest --isolated --no-usage-statistics
   ```
   - `--isolated` : 평소 크롬과 섞이지 않는 **임시 크롬**으로 열고, 끄면 기록을 지워요
   - `--no-usage-statistics` : 사용 통계를 구글에 보내지 않아요 (기본은 보내요)
3. Claude Code를 다시 켜고 **직접 승인** → `/mcp`에서 `list_console_messages`, `list_network_requests`, `take_screenshot` 같은 도구가 보이면 성공
4. 공식 문서는 Claude Code 플러그인 방식(`/plugin marketplace add ChromeDevTools/chrome-devtools-mcp`)도 안내해요. 이 키트는 범위를 좁히려고 위 명령을 써요. 최신 명령은 공식 문서에서 확인해요: https://github.com/ChromeDevTools/chrome-devtools-mcp · https://developer.chrome.com/docs/devtools/agents/get-started

## ⚠️ 알아 둘 것
- 이 MCP는 **브라우저에 열린 내용을 Claude에게 보여 줘요.** 로그인된 은행·메일 같은 페이지는 열지 않아요. `--isolated`로 따로 쓰는 이유예요.
- 성능 검사는 주소를 구글 CrUX 서비스에 보낼 수 있어요. localhost 연습사이트라 괜찮지만, 회사 내부 주소는 검사하지 않아요.
- 연습사이트 **원본은 고치지 않아요.** 고친 버전은 `결과/고친사이트/`에 복사해서 고쳐요.

## 🧭 기본 미션 (순서대로)
1. 새 터미널에서 연습사이트를 켠다: `cd 09_웹_크롬데브툴즈/연습사이트` → `python3 -m http.server 8781`
2. **추측 먼저:** 내 브라우저로 http://localhost:8781 을 보고, 이상한 점을 눈으로만 찾아 `결과/09_진단.md`에 적는다 (몇 개 찾았는지 세기)
3. Claude에게 DevTools로 **콘솔 오류**와 **네트워크 요청(실패·큰 파일)**을 확인하게 한다
4. 창을 **휴대폰 크기(375px)**로 바꿔 스크린샷을 찍게 하고, 화면이 넘치는 곳을 찾는다
5. 접근성(그림 설명 alt 등)과 성능 검사를 시켜, 찾은 문제를 표로 정리한다 → 2번의 내 목록과 비교
6. `결과/고친사이트/`에 복사본을 만들어 고치고, 다시 검사해서 문제가 0개인지 확인한 뒤 `정답_문제목록.md`로 채점한다
