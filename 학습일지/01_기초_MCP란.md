## 💡 새 개념

- **MCP = Claude에게 꽂는 콘센트, 도구 = 거기 꽂는 가전제품**: KOSIS 콘센트 하나에 가전제품 14개. 첫 도구가 실패하자 다른 도구로 바꿔 다시 시도함
- **콘센트는 두 종류**: `claude mcp add`로 내가 꽂는 멀티탭(`claude mcp list`에 보임) vs 앱이 달아 준 벽 콘센트 = 커넥터(목록에 안 보임)
- **기억 vs 확인**: MCP 없이 나온 숫자는 기억으로 짐작한 것. 크기는 맞았지만 최신(2025)은 몰랐다
- **나만의 정보는 짐작도 못 한다**: 통계 숫자는 기억으로라도 답했지만, 방금 만든 노션 페이지는 MCP 없이는 "알 수 없음"
- **범위(scope)**: project = 이 방(폴더)에만, user = 집 전체, 커넥터 = 건물 전체. 넓을수록 편하지만 노션처럼 내 데이터 전체를 보는 MCP는 조심
- **`.mcp.json` = 콘센트 설계도**: 주소만 있고 키는 없음. 폴더에 들어 있는 파일이라 처음 쓸 때 **주인 승인**이 필요. 승인할 때 "앞으로 전부 자동 승인" 대신 "이것만 승인"을 고름
- **콘센트 목록은 대화를 시작할 때 읽는다**: 그래서 노션을 꽂기 전에 시작한 대화에는 `.mcp.json` 노션이 없었다. 커넥터는 대화 중에도 바로 꽂혔다
- **다른 콘센트로 돌아갈 수 있다**: 노션 MCP가 없어도 크롬 조종 MCP로 노션 화면을 읽을 수는 있다 → 안전하려면 꽂힌 콘센트 **전체**를 봐야 함
- **도구가 많으면 헷갈리고 느려진다**: 고를 게 많아지고, 도구마다 사용 설명서를 미리 읽어 둬야 해서

## 📝 포트폴리오 한 줄

- **문제:** AI가 말하는 숫자가 진짜 확인한 건지, 기억으로 짐작한 건지 구분하기 어렵다
- **해결:** 같은 질문을 MCP를 끄고/켜고 두 번 물어 출처·기준 연도·부른 도구를 비교했고, 노션 공식 MCP를 검사표로 확인한 뒤 폴더 범위로 연결해 내 노션 페이지를 읽게 했다
- **효과:** 기억 답(약 36%, 2024)과 공식 통계(36.6%, 2025)의 차이를 직접 확인했고, MCP 없이는 "알 수 없음"이던 노션 페이지 문장을 MCP로 정확히 읽어 왔다

## 💬 느낀 점 (Claude가 대신 작성, 내가 확인)

- `claude mcp list`가 0개라서 놀랐는데, 앱 커넥터와 내가 꽂는 MCP가 따로라는 걸 알게 됐다. 콘센트 비유가 딱 맞았다.
- 기억으로 한 답도 대충은 맞았지만, MCP를 켜니 출처와 표 번호, 계산식까지 나와서 믿을 수 있는 숫자가 뭔지 알게 됐다.
- 노션에 몰래 적은 문장을 MCP가 그대로 맞히는 걸 보고, 편리한 만큼 내 노션 전체를 볼 수 있다는 점도 조심해야겠다고 느꼈다.
