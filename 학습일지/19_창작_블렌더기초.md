## 💡 새 개념

- **블렌더 = 사진 스튜디오**: 뷰포트(스튜디오를 돌아다니는 눈), 오브젝트(소품), 카메라(삼각대 카메라), 조명, 렌더(셔터 누르기)
- **Claude + 블렌더 = 소품 목수**: 그림을 그리는 게 아니라 원기둥·공·상자 같은 블록을 **재서 조립**한다. 단순한 물건·배경 세트에 강하고, 사람 얼굴·동물 같은 곡선 조각은 약하다
- **GPT = 화가**: 사진 한 장은 빠르고 예쁘지만, 납작한 그림이라 돌려 볼 수 없고 다시 그리면 조금씩 달라진다
- **한 번 짓고 계속 찍기**: 3D의 진짜 장점은 같은 세트를 각도·빛·색만 바꿔 여러 장, 영상으로 뽑는 것 (이케아 같은 가구 카탈로그, 분양 광고, 쇼핑몰 색상 옵션 사진이 이 방식)
- **세트장 끝**: 카메라가 볼 쪽만 지어 두면 옆에서 볼 때 빈 공간이 드러난다 → 필요하면 벽을 더 세운다
- **부모-자식 묶기**: 손잡이·커피를 컵에 붙여 두면 컵을 옮길 때 같이 따라온다
- **역할 나누기 업데이트**: 3D 배치·각도 = 블렌더, 그림·실사 질감 = GPT, 글자·배치 = 피그마·HTML, 완성 = Claude
- **명령 옵션이 뒤 글자를 먹는 실수**: `claude mcp add -e`, `codex exec -i`처럼 여러 값을 받는 옵션은 뒤의 이름·설명까지 삼킨다 → 이름·설명을 옵션 **앞**에 둔다
- **여러 장은 한 장씩**: 그림 생성을 동시에 돌리면 "가장 최근 그림"을 집는 스크립트가 같은 그림을 두 번 가져올 수 있다
- **실제 상품은 모양 고정이 먼저**: 판매용 카탈로그는 3D 파일 > 치수+사진 > 3D 스캔 순서로 실물 정보를 주고, GPT에는 "배경만" 맡긴다
- **애니메이션 = 키프레임**: 시작과 끝만 정하면 블렌더가 사이를 채운다. 카메라·물건 움직임은 쉽고, 캐릭터는 어렵다 (20강에서)

## 📝 포트폴리오 한 줄

- **문제:** 썸네일·쇼츠 배경을 AI 그림으로만 만들면 매번 모양이 달라져 시리즈 느낌을 유지하기 어려웠다
- **해결:** 블렌더 MCP로 Claude에게 책상·섬 장면을 말로 짓게 하고, 카메라·빛만 바꿔 여러 장을 렌더했다. 그 렌더를 GPT에 넘겨 배치는 유지한 채 실사 질감만 입혔다
- **효과:** 한 장 0.5초로 같은 장면 10장(각도 8 + 낮·저녁)을 모양 변화 없이 뽑았고, "블렌더 배치 → GPT 실사"로 일관성과 사진 느낌을 함께 얻는 작업 흐름을 정리했다

## 💬 느낀 점 (Claude가 대신 작성, 내가 확인)

- 3D 프로그램은 처음인데, "책상 → 컵 → 화분"처럼 한 줄씩 말하니 장면이 차곡차곡 지어져서 신기했다. 매번 저장하는 습관도 자연스럽게 익혔다.
- GPT 그림이 더 예쁘지만, 각도를 바꾸면 화분 잎이나 노트가 조금씩 달라진다는 걸 직접 비교해 보고 알았다. 블렌더는 장난감 같아도 모양이 절대 안 바뀐다.
- 블렌더로 배치를 잡고 GPT로 실사 질감을 입히는 방법이 제일 마음에 들었다. 상세페이지나 시리즈 썸네일처럼 여러 장이 같아야 하는 작업에 써 보고 싶다.
