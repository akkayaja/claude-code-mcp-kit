## 💡 새 개념

- **목록에 안 보이는 콘센트가 가장 힘세다**: 크롬 조종·컴퓨터 조종은 커넥터 목록에 없지만, 클릭·타이핑으로 로그인된 사이트에서 무엇이든 할 수 있다 (🔴🔴)
- **위험 단어가 없는 위험 도구**: `send`·`delete`로 찾는 건 출발점일 뿐. `computer`(클릭)나 `execute_sql`(SQL 실행)처럼 "무엇이든 할 수 있는" 도구는 이름에 위험 단어가 없다
- **표시 한 줄만 믿지 않기**: 승인 기록은 저장돼 있고 실제로 작동하는데, `claude mcp list`는 "승인 대기"로 표시했다
- **메모 vs 잠금**: 지도에 적은 규칙은 메모일 뿐 실제로 막지 않는다. 진짜로 막으려면 권한 설정의 deny(절대 못 씀)나 ask(쓸 때마다 물어봄)를 쓴다. 잠금도 한 줄이라 지우면 풀리고, 폴더마다 따로 걸 수 있다
- **끄는 스위치는 여러 개**: 이 대화만(＋ 버튼) / 이 폴더만(`/mcp` Disable) / 전체(설정 → 커넥터 연결 끊기)

## 📝 포트폴리오 한 줄

- **문제:** AI에 연결된 도구가 많아지면서, 그중 무엇이 메일을 보내거나 데이터를 지우거나 결제할 수 있는지 알 수 없었다
- **해결:** 연결된 MCP 18종의 도구를 읽기/쓰기/보내기/삭제로 나누고 신호등 위험도를 매겨, 위험한 도구마다 사용 규칙과 잠금 후보를 정리했다
- **효과:** 🔴 11개를 찾아냈고, 이름만으로는 드러나지 않던 결제 도구(`buy_domain`)와 "무엇이든 하는" 도구(크롬·컴퓨터 조종)를 미리 파악했다

## 💬 느낀 점 (Claude가 대신 작성, 내가 확인)

- 10개쯤이라고 생각했는데, 위험한 콘센트만 11개라 놀랐다.
- 설정을 세세하게 다 알기보다는, 무엇이 위험한지만 알고 실제 설정은 필요할 때 Claude에게 부탁하면 되겠다고 정리했다.
- 이제 MCP를 실제로 써서 뭔가 만들어 보는 활용 실습을 하고 싶다.
