# 21. SNS 디자인 (Canva)

> **얻는 능력:** 원고만 주면 Claude가 **캔바에서 카드뉴스 디자인을 만들어 주게** 하는 능력

**왜 배우나요?** 콘텐츠 키트에서는 HTML로 카드뉴스를 만들었어요. 자유롭지만 디자인 감각이 필요했죠. 캔바는 **이미 잘 만든 틀(템플릿)**이 수천 개 있는 디자인 가게예요. 두 방법을 비교해 보고, 상황에 맞게 고를 수 있게 돼요.

## 📁 들어 있는 파일
- `카드뉴스_원고.md` – 가짜 카드뉴스 5장 원고 (겨울철 실내 식물 관리)
- `결과/` – 비교표와 내려받은 PNG를 저장할 곳

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 확인해요. 캔바가 **직접 만든 공식 MCP**(Canva AI Connector)예요.

**1. 캔바 계정(직접)** — canva.com에서 가입해요. 캔바 안내에 따르면 **무료(Canva Free) 계정도 연결할 수 있어요.**

**2. 이 폴더 전용으로 추가** — 터미널에서 직접 실행해요.
```bash
claude mcp add --scope project --transport http canva https://mcp.canva.com/mcp
```
→ "canva라는 이름으로 캔바 공식 서버를 이 폴더에서만 쓰게 꽂아 줘"라는 뜻이에요.

**3. 로그인(직접)** — Claude Code를 새로 켜고 `/mcp` → `canva` → **Authenticate** → 브라우저에서 **요청 권한 목록을 읽고** 허용은 내가 눌러요.

> 💡 데스크톱 앱이나 claude.ai의 **커넥터** 메뉴로도 연결할 수 있는데, 그 방법은 **Claude 유료 요금제**가 필요하다고 안내돼 있어요. Claude Code에서 위 명령으로 연결하는 게 이 키트의 기본이에요.
> 공식 안내: https://www.canva.com/help/mcp-agent-setup/ (주소가 자주 바뀌니 접속 안 되면 "Canva AI Connector"로 검색)

## ⚠️ 알아 둘 것
- **무료 계정의 한계:** 디자인 자동 생성은 캔바의 AI 사용량을 써요. 무료 계정은 횟수가 적을 수 있어요 → 한 번에 5장을 다 만들지 말고 **1장 먼저 만들어 보고** 마음에 들면 나머지를 만들어요. 정확한 한도는 공식 문서에서 최신 방법을 확인해요.
- **자동 채우기(Autofill)·브랜드 템플릿** 기능은 **무료 요금제에서는 안 돼요.** 이 강의에서는 쓰지 않아요.
- 캔바 MCP는 **내 캔바 계정 전체**의 디자인을 볼 수 있어요. 연습용 **폴더 하나**("MCP 연습")를 만들고 거기서만 작업하게 말해요.
- **공유·공개 게시는 하지 않아요.** 만들기 → 내려받기까지만.
- 브랜드 로고, 유명 캐릭터가 들어간 템플릿은 쓰지 않아요.
- 다 쓰면: `claude mcp remove canva --scope project` + 캔바 **설정 → 연결된 앱**에서 권한 취소

## 🧭 기본 미션 (순서대로)
1. 캔바에 직접 들어가 **"MCP 연습"** 폴더를 만들고, 카드뉴스 템플릿을 몇 개 구경한다 (어떤 스타일이 좋은지 메모)
2. `카드뉴스_원고.md`의 **1번 카드(표지)만** Claude에게 만들게 하고, 캔바에서 직접 열어 확인한다
3. 마음에 들면 2~5번 카드를 같은 스타일로 만들게 한다
4. 캔바에서 글자 하나를 **손으로** 고쳐 보고, 다음엔 Claude에게 말로 고쳐 달라고 해서 둘을 비교한다
5. PNG로 내려받아 `결과/캔바/`에 넣는다
6. 예전 HTML 카드뉴스 방법과 비교한 표를 `결과/비교표.md`로 만든다 (만드는 시간, 고치기 쉬움, 자유도, 비용)
