# 20. 3D 활용 — 썸네일·쇼츠 배경 (Blender)

> **얻는 능력:** 3D 장면을 **썸네일 배경 그림과 쇼츠 배경 영상**으로 뽑고, 그 위에 글자를 올려 완성하는 능력

**왜 배우나요?** 콘텐츠 키트에서는 HTML로 썸네일을 만들었죠. 이번엔 배경을 **내가 만든 3D 장면**으로 바꿔요. 장면은 그대로, 카메라만 돌리면 영상도 돼요. 마치 **회전 진열대 위 케이크를 한 바퀴 찍는 것**과 같아요.

## 📁 들어 있는 파일
- `썸네일_기획.md` – 만들 썸네일 2장, 쇼츠 배경 1개, 회전 영상 1개의 기획서 (가짜 채널)
- `결과/` – 렌더 그림, 영상, 글자 올린 HTML을 저장할 곳

## 🔌 연결하기
19번에서 연결한 **blender MCP를 그대로** 써요. 새로 설치할 건 없어요.
- 연결 전에 `공통/MCP_검사표.md`의 판정을 다시 한 번 봐요 (19번에서 한 것).
- 확인 명령:
  ```bash
  claude mcp get blender
  ```
  → blender MCP가 어디에, 어떤 범위로 연결돼 있는지 보여 줘요.
- 블렌더를 열고 `N` → **MCP for Blender** 탭에서 서버가 켜져 있는지 봐요.
- 영상 합치기는 **ffmpeg**(이미 `~/.local/bin/ffmpeg`에 있음)를 써요. 확인:
  ```bash
  ffmpeg -version
  ```
  → 첫 줄에 버전이 나오면 OK예요.

> 공식 문서: https://github.com/ahujasid/blender-mcp / ffmpeg: https://ffmpeg.org/documentation.html

## ⚠️ 알아 둘 것
- **글자는 렌더에 넣지 않아요.** 3D 글자는 고치기 어려워요. 배경만 렌더하고, 글자는 HTML로 올려요 (오타 수정이 1초).
- 렌더와 영상은 **시간이 오래 걸려요.** 연습할 땐 품질을 낮추고(샘플 수 적게), 프레임 수도 적게(예: 5초 × 24장 = 120장).
- 렌더 시작 전 저장! 블렌더가 멈추면 작업이 날아가요.
- 크기를 꼭 맞춰요: 썸네일 **1280×720(가로)**, 쇼츠 **1080×1920(세로)**.

## 🧭 기본 미션 (순서대로)
1. 19번의 장면 1 `.blend` 파일을 열고, `썸네일_기획.md`를 읽는다. 글자가 들어갈 **빈자리(왼쪽 40%)**를 카메라로 만든다
2. 1280×720으로 렌더해 `결과/썸네일_배경.png`로 저장한다
3. 카메라를 세로로 바꿔 1080×1920으로 렌더해 `결과/쇼츠_배경.png`로 저장한다
4. 카메라가 물건 둘레를 한 바퀴 도는 **턴테이블 애니메이션**(5초)을 만들고, 그림 여러 장(`결과/프레임/`)으로 렌더한다
5. ffmpeg로 그림들을 `결과/턴테이블.mp4`로 합친다 (`cd 20_창작_블렌더활용`으로 이 폴더에 들어간 뒤 직접 실행)
   ```bash
   ffmpeg -framerate 24 -i 결과/프레임/%04d.png -c:v libx264 -pix_fmt yuv420p 결과/턴테이블.mp4
   ```
   → "1초에 24장씩, 0001.png부터 순서대로 이어 붙여, 어디서나 재생되는 mp4로 만들어 줘"라는 뜻이에요.
6. `결과/썸네일.html`에서 배경 PNG 위에 제목 글자를 올리고, 브라우저에서 확인한다
