# 24. 데이터베이스 다루기 (Supabase)

> **얻는 능력:** 내 서비스의 데이터를 **진짜 데이터베이스에 담고, 한국어로 질문해서 꺼내 보는** 능력

**왜 배우나요?** 손님 명단·예약·주문이 쌓이면 엑셀로는 금방 한계가 와요. 데이터베이스는 **규칙이 있는 튼튼한 창고**예요. Supabase MCP를 꽂으면 SQL(데이터베이스 언어)을 몰라도 "별점 5점 책 보여 줘"라고 말하면 Claude가 SQL로 바꿔서 꺼내 줘요.

## 📁 들어 있는 파일
- `독서기록_가짜데이터.csv` – 가짜 독서 기록 40줄 (책 제목·저자 모두 지어낸 것)
- `테이블_설계.md` – 만들 테이블의 칸·규칙·연습 질문 (빈칸 ❓ 채우기)

## 🔌 연결하기
**연결 전에 `공통/MCP_검사표.md`로 확인**해요. (공식: Supabase가 직접 만든 원격 MCP)

1. **(직접)** [supabase.com](https://supabase.com) 로그인 → **New project** → 이름 `독서기록-연습`으로 **새 무료 프로젝트**를 만들어요. 비밀번호는 내가 정하고 Claude에게 알려 주지 않아요.
2. **(직접)** 프로젝트 **Settings → General**에서 **Project ID**(= `project_ref`, 영문 20자 정도)를 복사해요.
3. 키트 폴더에서 아래 명령을 실행해요. `내_프로젝트ID`를 2번 값으로 바꿔요.
   ```bash
   claude mcp add --scope project --transport http supabase "https://mcp.supabase.com/mcp?project_ref=내_프로젝트ID&features=database,docs,debugging"
   ```
   - `--scope project` : 이 키트 폴더에서만 쓰는 콘센트(`.mcp.json`에 적혀요)
   - `project_ref=...` : **연습 프로젝트 하나만** 열 수 있는 열쇠. 다른 프로젝트·계정 기능은 안 보여요
   - `features=database,docs,debugging` : 데이터베이스·문서·점검(보안 경고) 도구만 켜요 (엣지 함수·브랜치 같은 건 꺼 둠)
4. **(직접)** 일반 터미널에서 `claude` 실행 → `/mcp` → `supabase` 선택 → **Authenticate** → 브라우저에서 권한을 읽고 허용해요.
5. 미션이 끝나면 **읽기 전용**으로 바꿔요: `claude mcp remove supabase -s project` 후, 주소 끝에 `&read_only=true`를 붙여 다시 추가해요.

> 💡 데스크톱 앱에는 Supabase 커넥터가 이미 있어요. 하지만 커넥터는 **내 계정 전체**를 볼 수 있으니, 이번 강의는 프로젝트 하나로 묶인 위 방법을 써요.
> 공식 문서: https://supabase.com/docs/guides/getting-started/mcp

## ⚠️ 알아 둘 것
- **진짜 서비스(운영) 데이터베이스에는 절대 연결하지 않아요.** Claude가 실수로 표를 지우면 되돌리기 어려워요. 연습은 연습 프로젝트에서만!
- **읽기 전용(`read_only=true`)** = 창고를 유리창 너머로만 보는 것. 표를 만들 땐 꺼야 하지만, 그 뒤 질문만 할 땐 켜 두는 게 안전해요.
- Claude가 SQL을 실행하기 전에 **어떤 SQL인지 꼭 읽고** 허용해요. `drop`, `delete`, `truncate`가 보이면 멈추고 물어보세요.
- 무료 프로젝트는 오래 안 쓰면 **일시 정지**될 수 있어요. 다 쓰면 대시보드에서 직접 정지하거나 지워요.

## 🧭 기본 미션 (순서대로)
1. `테이블_설계.md`를 읽고 ❓ 칸을 채운다. CSV를 열어 **비어 있는 칸이 어디인지** 먼저 직접 찾아본다.
2. Claude에게 설계대로 `reading_log` 테이블을 만들어 달라고 한다 → 대시보드 **Table Editor**에서 직접 눈으로 확인
3. CSV 40줄을 넣는다 (Claude가 넣거나, 내가 Table Editor의 **Import data from CSV**로 넣기) → `select count(*)`가 **40**인지 확인
4. `테이블_설계.md`의 연습 질문 5개를 **한국어로** 묻는다. 답마다 Claude가 쓴 SQL을 보여 달라 하고, 1번 질문은 CSV에서 직접 세어 답을 맞춰 본다
5. **RLS(행 수준 보안)**를 켠다. 비유: 아파트 출입카드 — 건물(테이블)에 들어와도 **내 카드로 열리는 집(줄)만** 들어갈 수 있어요. 켠 뒤 정책이 없으면 앱에서는 **아무 줄도 안 보이는 것**까지 확인 (Claude에게 `get_advisors`로 보안 경고도 봐 달라고 하기)
6. 연결을 `read_only=true`로 바꾸고, "책 하나 지워 줘"라고 해서 **거절되는 것**을 확인한다

## 🔥 도전 미션
- "나만 내 기록을 볼 수 있게" 하는 RLS 정책을 만들고, 왜 그렇게 되는지 한 줄씩 설명 듣기
- 월별 완독 수를 표로 뽑아 22번(다이어그램)이나 11번(시트)으로 그래프 만들기

```
테이블_설계.md대로 reading_log 테이블을 만드는 SQL을 먼저 보여 줘. 각 줄이 무슨 뜻인지 설명하고, 내가 OK하면 실행해 줘.
```
```
별점 5점 준 책을 장르별로 세어 줘. 쓴 SQL도 보여 주고, SQL을 한 줄씩 한국어로 풀어 줘.
```
```
reading_log 테이블에 RLS를 켜면 무엇이 달라지는지 아파트 출입카드 비유로 설명하고, 켜는 SQL을 보여 줘.
```
