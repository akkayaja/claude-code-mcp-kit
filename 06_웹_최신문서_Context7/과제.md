# 06 과제: 빵집 소개 카드 한 장

> 같은 과제를 **Context7 없이 한 번, 있이 한 번** 시켜서 결과를 비교해요.

## 만들 것
가짜 동네 빵집 "보리밭 베이커리"의 소개 카드 HTML 파일 **1개**.

## 조건
1. **Tailwind CSS** (웹 꾸미기 도구)를 써요. 설치 없이 `<script>` 한 줄(CDN)로 불러와요.
2. 빵집만의 색 하나를 **직접 정해서** 이름 붙여 쓰기: `보리색` = `#c8a165` (예: 제목 글자색)
3. 카드 안에: 가게 이름, 한 줄 소개, 대표 빵 3개(이름·가격), "영업 중" 배지
4. 휴대폰 화면에서도 카드가 화면 밖으로 넘치지 않게

## 저장 위치
- Context7 없이 만든 것: `결과/카드_없이.html`
- Context7 켜고 만든 것: `결과/카드_있이.html`

## 비교할 것 (힌트)
Tailwind는 큰 버전 변경(3 → 4)이 있었어요. 특히 아래 두 가지가 바뀌었어요.
- CDN으로 불러오는 `<script>` 주소
- 나만의 색을 정하는 방법 (설정 파일 방식 → CSS 안에 적는 방식)

Claude가 **어느 버전 방식으로 썼는지**, 그리고 **브라우저에서 보리색이 실제로 나오는지** 확인해 보세요.
