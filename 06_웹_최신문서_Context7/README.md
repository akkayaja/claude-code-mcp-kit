# 06. 최신 문서 찾기 (Context7)

> **얻는 능력:** Claude가 **옛날 방식으로 코드를 짜는 실수**를 알아채고, 최신 공식 문서를 보게 해서 바로잡는 능력

**왜 배우나요?** Claude는 공부를 마친 날 이후에 바뀐 내용을 몰라요. 도구가 새 버전으로 바뀌면 옛 방식 코드를 자신 있게 써 줄 때가 있어요. Context7은 여러 프로그램의 **최신 공식 문서를 찾아다 주는 도서관 사서** 같은 MCP예요.

## 📁 들어 있는 파일
- `과제.md` – 같은 과제(빵집 소개 카드)를 Context7 없이 / 있이 시켜 보는 비교 과제와 비교표

## 🔌 연결하기
Context7은 **Upstash 회사가 직접 만든** MCP예요. 문서를 읽기만 하는 도구 2개(`resolve-library-id` 라이브러리 찾기, `query-docs` 문서 읽기)가 있어요.
1. **검사표로 먼저 확인:** `공통/MCP_검사표.md` (출처: github.com/upstash/context7)
2. 키 없이 시작해요. 키트 맨 위 폴더에서 직접 실행해요.
   ```bash
   claude mcp add --scope project context7 -- npx -y @upstash/context7-mcp
   ```
   - `npx -y @upstash/context7-mcp` : 공식 패키지를 받아 내 컴퓨터에서 켜요
3. Claude Code를 다시 켜고 **직접 승인** → `/mcp`에서 도구 2개가 보이면 성공
4. 쓰다 보면 "요청이 너무 많다"는 메시지가 날 수 있어요. 그때는 context7.com에서 **무료 키를 직접 발급**받아 `.env`에 넣어요 (키는 설정 파일에 직접 쓰지 않아요).
5. 공식 문서에는 `npx ctx7 setup --claude`(로그인 + 스킬까지 설치) 방법도 있어요. 이 키트는 범위를 좁히려고 위 명령을 써요. 최신 명령은 공식 문서에서 확인해요: https://context7.com/docs/resources/all-clients

## ⚠️ 알아 둘 것
- Context7은 **공개 문서만** 찾아요. 내 회사 자료나 비공개 코드를 질문에 붙여 넣지 않아요.
- 문서를 가져왔다고 늘 맞는 건 아니에요. 마지막 확인은 **공식 사이트를 내 눈으로** 해요.
- 질문 끝에 `use context7`을 붙이면 Claude가 이 MCP를 쓰라는 신호로 알아들어요.

## 🧭 기본 미션 (순서대로)
1. **추측 먼저:** `과제.md`를 읽고, Context7 없이 만든 카드에서 보리색이 제대로 나올지 짐작해 적는다
2. `/mcp`에서 context7을 **끈 채로** 과제를 시킨다 → `결과/카드_없이.html` → 브라우저로 열어 본다
3. context7을 **켜고** 새 대화에서 같은 과제 + `use context7` → `결과/카드_있이.html`
4. 두 파일의 `<script>` 주소와 색 정하는 방법을 `과제.md` 비교표에 적는다
5. Tailwind 공식 문서(Play CDN 쪽)를 직접 열어 어느 쪽이 최신 방식인지 확인한다
6. 휴대폰 크기로 창을 줄여 두 카드 모두 넘치지 않는지 본다

## 🔥 도전 미션
- 내가 전에 쓴 도구(예: 1단계 키트의 파이썬 라이브러리) 하나를 골라 "최신 버전에서 바뀐 점 3가지"를 Context7로 찾아보기
- `CLAUDE.md`에 "라이브러리 코드를 쓸 때는 Context7로 최신 문서를 먼저 확인" 규칙을 넣을지 고민해 보기 (넣기 전에 장단점 적기)
