# 조사 계획

## 1. 주제 고르기 (하나만)
- [ ] 홈카페 (예시)
- [ ] 겨울 실내 식물 (21번 카드뉴스와 연결)
- [ ] 아침 루틴 / 책상 정리 (20번 썸네일과 연결)
- [ ] 내가 정한 주제: ____________

내가 예상하는 '잘 되는 제목' 3개 (조사 전에 먼저 적기):
1. 
2. 
3. 

## 2. 모을 항목 → `결과/영상목록.csv`
| 열 이름 | 뜻 |
|---|---|
| 조사날짜 | 예: 2026-11-24 |
| 순위 | 조회수 순서 |
| 제목 | 영상 제목 |
| 채널 | 채널 이름 (공개 정보) |
| 조회수 | 숫자만 |
| 올린날짜 | YYYY-MM-DD |
| 길이 | 분:초 (60초 이하면 쇼츠 표시) |
| 링크 | 영상 주소 |

❌ 넣지 않는 것: 댓글 작성자 이름, 프로필, 댓글 전문

## 3. 사용량 계획
- 검색: **1~2번**
- 영상 상세: 10~20개
- 댓글: 상위 3~5개 영상만, 영상당 최대 50개

## 4. 보고서 틀 → `결과/분석보고서.md`
```
# [주제] 유튜브 조사 보고서 (조사일: )
## 한눈에 보기 (3줄)
## 조회수 상위 5개
## 제목 패턴 (숫자로)
- 숫자가 들어간 제목: N개 / 전체 N개
- 질문형 제목: 
- 평균 글자 수: 
- 자주 나오는 낱말 TOP 5: 
## 시청자가 원하는 것 (댓글 요약, 이름 없이)
## 다음 영상 아이디어 3개
| 아이디어 | 가제목 | 근거 (위 숫자/댓글 중 어느 것) |
## 내 예상과 비교
## 한계 (데이터 수가 적음, 조사 날짜 기준 등)
```
