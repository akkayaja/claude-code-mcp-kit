# 23. 유튜브 데이터 (YouTube Data 커넥터)

> **얻는 능력:** 한 주제의 인기 영상을 모아 **제목 패턴·시청자 요청을 찾고, 다음 영상 아이디어를 근거 있게** 뽑는 능력

**왜 배우나요?** "요즘 뭐가 잘 되지?"를 감으로 정하면 매번 흔들려요. 인기 영상의 제목·조회수·댓글은 **시장 조사 노트**예요. Claude가 대신 모으고 정리하면, 나는 **판단**만 하면 돼요.

## 📁 들어 있는 파일
- `조사_계획.md` – 주제 고르기, 모을 항목, 보고서 틀
- `결과/` – CSV와 보고서를 저장할 곳

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 확인해요. 이번엔 **새로 설치하지 않아요.** 데스크톱 앱에 이미 **YouTube Data 커넥터**가 연결돼 있어요.
- 확인: 데스크톱 앱 **설정 → 커넥터**에서 YouTube Data가 켜져 있는지 봐요.
- Claude Code 대화창에서 `/mcp`로 도구 목록을 보면 이런 도구가 있어요:
  | 도구 | 하는 일 |
  |---|---|
  | `search_videos` | 검색어로 영상 찾기 |
  | `get_video_details` | 조회수·좋아요·올린 날짜 |
  | `get_channel_statistics` | 채널 구독자·영상 수 |
  | `get_video_comments` | 댓글 읽기 |
  | `get_transcripts` | 자막(대본) 읽기 |
  | `get_trending_videos` | 지금 인기 급상승 영상 |
- 검사표 체크 포인트: **읽기 전용**인지(댓글 쓰기·업로드 도구가 없는지) 직접 확인해요.
- 안 보이면 커넥터를 켜고, 계정 연결이 필요하면 그 단계는 **직접** 해요.

> 참고(유튜브 공식 API 사용량 규칙): https://developers.google.com/youtube/v3/getting-started#quota

## ⚠️ 알아 둘 것
- **공개 데이터만** 봐요. 비공개·회원 전용 영상은 다루지 않아요.
- **댓글 작성자 이름·프로필은 파일에 저장하지 않아요.** 댓글은 "무엇을 원하나"만 요약해요. 댓글 문장을 그대로 길게 옮기지 않아요.
- **사용량(쿼터) 아끼기:** 유튜브 API는 하루 사용량이 정해져 있고, **검색이 특히 비싸요**(일반 조회의 약 100배). 검색은 한두 번, 영상은 **10~20개**까지만.
- 숫자는 **조사한 날짜**와 함께 적어요. 조회수는 매일 바뀌어요.
- 남의 영상 제목·썸네일을 그대로 베끼지 않아요. **패턴**만 배워요.

## 🧭 기본 미션 (순서대로)
1. `조사_계획.md`를 보고 주제를 하나 고른다 (예: 홈카페). 내가 예상하는 '잘 되는 제목'을 3개 먼저 적는다
2. 그 주제로 영상 10~20개를 찾고, 제목·채널·조회수·올린 날짜·길이를 `결과/영상목록.csv`로 저장하게 한다
3. CSV를 직접 열어 조회수 상위 3개를 내 눈으로 확인한다 (Claude가 말한 순서와 같은지)
4. 제목 패턴을 분석하게 한다: 숫자 사용, 질문형, 길이, 자주 나오는 낱말
5. 상위 3~5개 영상의 댓글에서 **시청자가 자주 요청하는 것**을 요약하게 한다 (이름 없이)
6. 다음 영상 아이디어 3개를 근거와 함께 `결과/분석보고서.md`로 정리하고, 1번에서 내가 예상한 것과 비교한다

## 🔥 도전 미션
- 같은 주제를 '쇼츠'와 '긴 영상'으로 나눠 조회수 패턴이 어떻게 다른지 비교하기
- CSV로 콘텐츠 키트 채널 통계 때처럼 HTML 차트(조회수 막대그래프) 만들기
- 22번 엑스칼리드로로 "아이디어 → 근거" 그림 그리기
