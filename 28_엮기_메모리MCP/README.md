# 28. 기억하는 Claude (Memory MCP)

> **얻는 능력:** 새 대화를 열어도 Claude가 **내 프로젝트의 사실을 기억해 꺼내 쓰게** 하는 능력

**왜 배우나요?** Claude는 대화를 새로 열면 지난 이야기를 잊어요. 메모리 MCP는 **Claude 전용 수첩**이에요. "공방 정원은 6명" 같은 사실을 수첩에 적어 두면, 다음 대화에서 수첩을 펼쳐 찾아 써요.

## 📁 들어 있는 파일
- `가짜_프로젝트_정보.md` – 수첩에 적을 가짜 사실들 (점·선·메모 모양으로 정리돼 있어요)

## 🔌 연결하기
**연결 전에 `공통/MCP_검사표.md`로 확인**해요. 이건 서비스 회사 것이 아니라 **MCP를 만든 곳(Model Context Protocol)의 공식 예제 서버**예요. 내 컴퓨터에서 실행되고, 인터넷 계정이 필요 없어요.

1. 수첩 파일을 둘 폴더를 만들어요 (키트 폴더에서):
   ```bash
   mkdir -p 28_엮기_메모리MCP/결과
   ```
2. 메모리 MCP를 이 키트 폴더 범위로 추가해요:
   ```bash
   claude mcp add --scope project --env MEMORY_FILE_PATH="$PWD/28_엮기_메모리MCP/결과/memory.jsonl" --transport stdio memory -- npx -y @modelcontextprotocol/server-memory
   ```
   - `--env MEMORY_FILE_PATH=...` : 수첩 파일을 **어디에 둘지** 정해요. 안 정하면 찾기 어려운 곳에 생겨요
   - `"$PWD/..."` : 지금 폴더 기준 전체 경로로 바꿔 적어 줘요 (폴더 이름에 띄어쓰기가 있어서 따옴표 필수)
   - `-- npx -y @modelcontextprotocol/server-memory` : 공식 메모리 서버를 빌려 실행 (이름 **글자 하나까지** 확인!)
3. `claude` 실행 → 이 폴더의 MCP를 허용할지 물으면 확인 후 허용 → `/mcp`에서 `memory`가 ✔인지 확인

> 공식 문서: https://github.com/modelcontextprotocol/servers/tree/main/src/memory

## ⚠️ 알아 둘 것
- 수첩 파일(`memory.jsonl`)은 **그냥 글자 파일**이에요. 암호화되지 않아요. **비밀번호·키·개인정보는 절대 저장하지 않아요.**
- 수첩은 Claude가 **스스로 고칠 수도** 있어요. 저장·삭제할 때마다 무엇을 하는지 보고 허용해요.
- `결과/memory.jsonl`은 커밋 전에 꼭 열어 보고, 올리기 싫으면 `.gitignore`에 넣어요.
