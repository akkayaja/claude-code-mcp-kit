# 08. 공공데이터 (통계청 KOSIS)

> **얻는 능력:** 국가 통계를 Claude에게 찾아오게 하고, **출처가 붙은 그래프 한 장 보고서**로 만들고, 숫자를 내 눈으로 검증하는 능력

**왜 배우나요?** 발표 자료·블로그·업무 보고에서 "요즘 1인 가구가 많다"보다 "**○○년 ○○% → ○○년 ○○%**"가 훨씬 힘이 있어요. 통계청 KOSIS MCP는 국가 통계 창고의 문을 Claude에게 열어 줘요. 단, 숫자는 **반드시 원본과 맞춰 봐요.**

## 📁 들어 있는 파일
- `보고서_양식.md` – 짐작 / 출처 / 숫자 표 / 그래프 / 검증표 / 한 줄 요약 칸

## 🔌 연결하기
이 KOSIS MCP는 **이미 데스크톱 앱 커넥터로 연결돼 있어요.** 새로 설치하지 않아요.
1. **검사표로 먼저 확인:** 02번 지도에서 KOSIS 칸을 다시 보고, 도구가 **읽기만** 하는지 확인해요 (예: `search_statistics` 통계 찾기, `quick_trend` 추이 보기, `get_statistics_data` 숫자 가져오기)
2. 데스크톱 앱 대화창의 커넥터 목록에서 KOSIS가 **켜져 있는지** 확인해요
3. Claude Code 터미널에서 쓰고 싶다면 `claude mcp list`에 있는지 먼저 봐요. 없으면 이번 강의는 **데스크톱 앱**에서 해요
4. 다른 컴퓨터에서 새로 연결해야 한다면 앱의 커넥터 목록에서 찾아 연결해요. 통계청 공식 Open API 안내: https://kosis.kr/openapi/
   (키 발급이 필요한 방식이면 **내가 직접** 발급하고 `.env`에 넣어요)

## ⚠️ 알아 둘 것
- 통계마다 **기준이 달라요.** "1인 가구 비율"도 조사(인구주택총조사/등록센서스)와 단위(%/가구 수)가 다를 수 있어요. 출처 칸을 꼭 채워요.
- 가장 최근 연도 값은 **잠정치**일 수 있어요. 표 아래 각주를 봐요.
- 숫자를 그럴듯하게 만들어 내지 않도록, "가져온 숫자만 써 줘, 없으면 없다고 말해 줘"라고 부탁해요.
- KOSIS 웹사이트는 **보기만** 해요. 로그인할 필요 없어요.

## 🧭 기본 미션 (순서대로)
1. **추측 먼저:** `보고서_양식.md`를 복사해 `결과/08_보고서.md`로 만들고, 1번 칸(짐작)을 채운다
2. Claude에게 "1인 가구 비율" 통계표를 **찾기만** 하게 한다 → 후보 2~3개 중 하나를 내가 고르고 출처 칸을 채운다
3. 최근 10년 정도의 숫자를 가져와 숫자 표를 채우게 한다
4. 그래프를 만들어 `결과/08_그래프.png`로 저장하게 한다 (제목·단위·출처를 그래프 아래에)
5. **내 눈으로 검증:** kosis.kr에서 같은 통계표를 직접 검색해 연도 3개를 비교하고 검증표를 채운다
6. 한 줄 요약과 "이 숫자로 말할 수 없는 것"을 쓴다

## 🔥 도전 미션
- 시도별 1인 가구 비율을 비교해 가장 높은 곳 3곳 찾기 (그래프 1장 더)
- 관심 있는 다른 통계(예: 출생아 수, 반려동물 가구)로 같은 보고서 한 장 더 만들기
- 보고서를 HTML 한 장(`결과/08_보고서.html`)으로 꾸며 보기
