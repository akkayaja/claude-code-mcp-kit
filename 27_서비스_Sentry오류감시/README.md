# 27. 오류 감시하기 (Sentry)

> **얻는 능력:** 손님 화면에서 난 오류를 **내가 못 봐도 기록으로 받아 보고, Claude와 함께 원인을 찾아 고치는** 능력

**왜 배우나요?** 사이트를 올리면 손님 휴대폰에서 무슨 일이 일어나는지 나는 볼 수 없어요. Sentry는 **가게에 단 CCTV + 고장 신고함**이에요. 오류가 나면 언제·어디서·몇 번 났는지 자동으로 적어 두고, Sentry MCP로 Claude가 그 기록을 읽어요.

## 📁 들어 있는 파일
- `고장난사이트/` – 버튼 3개가 **일부러 고장 난** 가짜 주문 페이지 (`index.html`, `app.js`)
- `고장난사이트/sentry설정.example.js` – DSN(오류를 보낼 주소)을 넣는 설정 예시. `.env.example`처럼 **복사해서** 써요
- `정답_버그3개.md` – 채점용. 미션이 끝날 때까지 열지 않아요

## 🔌 연결하기
**연결 전에 `공통/MCP_검사표.md`로 확인**해요. (공식: Sentry가 직접 만든 원격 MCP)

1. **(직접)** [sentry.io](https://sentry.io)에서 무료 가입 → 새 프로젝트 만들기 → 플랫폼 **Browser JavaScript** → 이름 `monggle-practice`
2. **(직접)** 프로젝트 **Settings → Client Keys (DSN)**에서 DSN을 복사 → `sentry설정.example.js`를 `결과/고장난사이트/sentry설정.js`로 복사해 붙여 넣기 (채팅창에 붙여 넣지 않아요)
3. 조직 이름(org slug)과 프로젝트 이름(project slug)을 확인해요. 주소창 `https://내조직.sentry.io/...`의 `내조직` 부분이 org slug예요
4. 키트 폴더에서 실행 (`내조직`만 바꾸기):
   ```bash
   claude mcp add --scope project --transport http sentry https://mcp.sentry.dev/mcp/내조직/monggle-practice
   ```
   → 주소 끝에 조직/프로젝트를 붙이면 **이 연습 프로젝트만** 보이는 콘센트가 돼요
5. **(직접)** `claude` → `/mcp` → `sentry` → 브라우저에서 로그인·권한 허용

> 공식 문서: https://mcp.sentry.dev · SDK 설치: https://docs.sentry.io/platforms/javascript/install/cdn/

## ⚠️ 알아 둘 것
- Sentry로 가는 오류 기록에 **이름·전화번호 같은 개인정보가 섞이지 않게** 해요. 이 연습 페이지에는 개인정보가 없어요.
- 무료 플랜은 한 달에 받을 수 있는 오류 개수에 한도가 있어요. 버튼을 수백 번 누르지 마세요.
- Sentry MCP에는 이슈 상태를 바꾸는 등 **쓰기 도구**도 있어요. "읽기만" 할 때는 그렇게 말해요.
- 원본 `고장난사이트/`는 그대로 두고 `결과/`에 복사해서 고쳐요.

## 🧭 기본 미션 (순서대로)
1. 원본을 복사하고 실행한다
   ```bash
   mkdir -p 27_서비스_Sentry오류감시/결과 && cp -R 27_서비스_Sentry오류감시/고장난사이트 27_서비스_Sentry오류감시/결과/
   cd 27_서비스_Sentry오류감시/결과/고장난사이트 && python3 -m http.server 8771
   ```
   → http://localhost:8771 을 열고 개발자 도구 콘솔에 `Sentry 연결됨`이 보이는지 확인
2. 버튼 ①②③을 **한 번씩** 누른다. 화면과 콘솔에 무슨 일이 생기는지 **직접 먼저** 적어 둔다
3. Sentry 웹에서 **Issues**에 이슈 3개가 생겼는지 눈으로 확인한다
4. Claude에게 Sentry MCP로 이슈 목록을 읽게 하고, **오류 이름 · 파일 · 몇째 줄 · 횟수**를 표로 받는다 → 3번에서 본 것과 비교
5. 이슈마다 원인을 추측해 내가 먼저 말하고 → Claude 설명과 비교 → `결과/` 쪽 `app.js`를 고친다
6. 다시 버튼을 눌러 새 오류가 없는지 확인하고, Sentry에서 이슈를 **Resolved**로 바꾼 뒤 `정답_버그3개.md`로 채점한다
