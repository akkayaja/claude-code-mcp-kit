# 정답: 숨어 있는 버그 3개

> 미션을 다 하고 **채점할 때만** 열어요.

| # | 버튼 | Sentry에 보이는 오류 이름 | 원인 | 고치는 법 |
|---|---|---|---|---|
| ① | 장바구니 담기 | `ReferenceError: addToCrat is not defined` | 함수 이름 **오타**. 만든 함수는 `addToCart`인데 `addToCrat`(r과 a 순서 바뀜)로 불렀어요 | `addToCrat(...)` → `addToCart(...)` |
| ② | 합계 보기 | `Error: 합계가 숫자가 아니에요: NaN` | 데이터 칸 이름은 한글 `가격`인데 코드는 영어 `price`를 찾아요. 없는 칸 = `undefined`, 숫자 + undefined = `NaN`(숫자 아님) | `상품.price` → `상품.가격` |
| ③ | 예약 불러오기 | `SyntaxError: ... is not valid JSON` (브라우저마다 문구가 조금 달라요) | JSON은 **큰따옴표(")만** 허용해요. 저장된 글이 작은따옴표(')로 돼 있어요 | `'{"날짜": "2026-12-05", "시간": "14:00"}'` 처럼 큰따옴표로 |

## 채점 기준
- [ ] 3개 모두 Sentry 이슈 목록에 따로따로 나타났다 (같은 오류는 한 이슈로 묶여 **횟수**가 올라가요)
- [ ] Claude가 MCP로 읽은 **오류 위치(app.js 몇째 줄)**가 실제 줄과 맞았다
- [ ] 고친 뒤 버튼을 다시 눌러 새 오류가 안 생겼다
- [ ] Sentry에서 3개 이슈를 **Resolved(해결됨)**로 바꿨다

## 배울 점
- ①은 **이름 오타**, ②는 **데이터 모양 불일치**, ③은 **형식 규칙 위반** — 실제 서비스 오류의 대부분이 이 세 종류예요.
- ②는 오류를 일부러 던지지 않았다면 화면에 "NaN원"만 뜨고 **조용히** 틀렸을 거예요. 조용한 오류가 더 무서워요.
