# 그릴 것 — 다이어그램 3개

> 한 그림에 상자는 10개 이하로. 많으면 나눠 그려요.

## 다이어그램 1. 유튜브 영상 제작 흐름 (흐름도, 왼쪽 → 오른쪽)
```
아이디어 메모 → 주제 정하기 → 대본 쓰기 → 촬영 → 편집 → 썸네일 만들기 → 업로드 → 댓글 확인
```
- '대본 쓰기'와 '썸네일 만들기' 옆에 작은 메모: "Claude가 도와줌"
- '댓글 확인'에서 '아이디어 메모'로 돌아가는 **점선 화살표** (다음 영상 아이디어)
- 색: 준비 단계 = 파랑, 만들기 = 초록, 내보내기 = 주황

## 다이어그램 2. 내 MCP 연결 구조 (가운데에서 퍼지는 그림)
- 가운데: **Claude Code** (큰 동그라미)
- 둘레 상자: 이 키트에서 연결한 MCP들 (예: Playwright, 노션, 구글 시트, 블렌더, 캔바, 엑스칼리드로, 유튜브 데이터)
- 선 위 글씨: 읽기만 / 읽기+쓰기
- 범위 표시: 이 폴더만(project) = 실선, 내 컴퓨터 전체(user) = 굵은 선, 데스크톱 커넥터 = 점선
- 실제 내 상태는 `claude mcp list`와 02번 'MCP 지도'를 보고 채워요 (계정 이메일은 쓰지 않기)

## 다이어그램 3. 주간 루틴 (Mermaid로, 표 또는 타임라인)
| 요일 | 할 일 |
|---|---|
| 월 | 지난주 영상 숫자 확인 (23번 유튜브 데이터) |
| 화 | 다음 영상 주제 3개 고르기 |
| 수 | 대본 쓰기 |
| 목 | 촬영 |
| 금 | 편집 + 썸네일 |
