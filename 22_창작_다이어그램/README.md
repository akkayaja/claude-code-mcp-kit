# 22. 말로 그리는 다이어그램 (Excalidraw)

> **얻는 능력:** "이게 이거랑 연결돼"라고 **말만 하면 손그림 느낌 다이어그램**이 나오게 하는 능력

**왜 배우나요?** 일의 흐름을 글로 설명하면 길어지는데, 상자와 화살표 하나면 한눈에 보여요. 엑스칼리드로(Excalidraw)는 **화이트보드에 마커로 쓱쓱 그린 느낌**의 무료 그림판이에요.

## 📁 들어 있는 파일
- `그릴것.md` – 그릴 다이어그램 3개 (유튜브 영상 제작 흐름 / 내 MCP 연결 구조 / 주간 루틴)
- `결과/` – PNG·SVG·`.excalidraw` 파일, Mermaid 문서를 저장할 곳

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 확인해요. Excalidraw 팀 GitHub(`excalidraw/excalidraw-mcp`)에 있는 **공식 MCP 앱**이에요. 계정·키가 필요 없어요.

**방법 A. 데스크톱 앱 / claude.ai (그림이 대화창에 바로 보여요, 추천)**
- 설정 → **커넥터** → 둘러보기에서 **Excalidraw**를 찾아 켜요 (직접).
- 목록에 없으면 **사용자 지정 커넥터 추가** → 주소 `https://mcp.excalidraw.com/mcp`
- 커넥터 사용 조건은 Claude 요금제에 따라 다를 수 있어요. 공식 문서에서 최신 방법을 확인해요: https://claude.com/connectors/excalidraw-app-demo

**방법 B. Claude Code (이 폴더에서만)**
```bash
claude mcp add --scope project --transport http excalidraw https://mcp.excalidraw.com/mcp
```
→ "excalidraw라는 이름으로 엑스칼리드로 공식 서버를 이 폴더에서만 쓰게 꽂아 줘"라는 뜻이에요.
- ⚠️ 이 MCP는 **대화창 안에 그림판을 띄우는 'MCP 앱'** 방식이라, 터미널에선 그림이 안 보일 수 있어요. 그럴 땐 아래 대체 방법을 써요.

**방법 C. MCP 없이 (대체 방법)**
- **Mermaid:** 마크다운 안에 글로 쓰는 다이어그램이에요. 설치 없이 GitHub·옵시디언에서 그림으로 보여요.
- **`.excalidraw` 파일:** Claude에게 파일로 만들게 하고 → excalidraw.com에서 **열기**로 불러와요.

> 공식 저장소: https://github.com/excalidraw/excalidraw-mcp

## ⚠️ 알아 둘 것
- excalidraw.com의 **공유 링크**는 그림을 인터넷에 올리는 거예요. 개인정보·실제 회사 이름은 넣지 말고, 링크는 필요할 때만 만들어요.
- PNG/SVG 내보내기는 그림판 메뉴에서 **내가 직접** 눌러요. (PNG = 사진, SVG = 아무리 키워도 안 깨지는 그림)
- 다 쓰면: 커넥터 끄기 또는 `claude mcp remove excalidraw --scope project`

## 🧭 기본 미션 (순서대로)
1. `그릴것.md`의 다이어그램 1을 종이에 3분 동안 **직접** 그려 본다 (상자 몇 개, 화살표 몇 개?)
2. 방법 A(또는 B)로 연결하고, 다이어그램 1을 **말로** 그리게 한다
3. 말로 고친다: "썸네일 상자를 대본 옆으로 옮겨 줘", "검토 단계 색을 노란색으로" 등 3번 이상
4. 그림판에서 **PNG와 SVG**로 내보내 `결과/`에 저장한다 (`1_영상제작흐름.png`, `.svg`)
5. 다이어그램 2(내 MCP 연결 구조)를 그린다. 02번에서 만든 'MCP 지도'를 참고해요
6. 다이어그램 3(주간 루틴)은 **Mermaid**로 `결과/3_주간루틴.md`에 만들고, 엑스칼리드로 그림과 비교한다

## 🔥 도전 미션
- 지금까지 연결한 MCP 전체를 '콘센트 멀티탭' 그림으로 그리기 (켜진 것/꺼진 것 색 구분)
- 같은 그림을 Mermaid와 Excalidraw로 각각 만들고, 고치기 쉬운 쪽을 골라 이유 쓰기
