# 이슈로 만들 메모 (가짜)

> 가상의 프로젝트 "나의 독서기록 웹페이지"를 만들면서 적어 둔 메모예요.
> 연습 저장소 `mcp-practice`에 **이슈(할 일 카드)** 로 옮길 거예요.

## 메모 (막 적은 것)
1. 모바일에서 책 표지 사진이 화면 밖으로 삐져나감. 버그!
2. 별점(1~5) 기능 넣고 싶다
3. README에 사용법 설명이 하나도 없음
4. 날짜가 2026-12-01이 아니라 12/1/2026으로 나옴 → 한국식으로 고치기
5. 다 읽은 책 / 읽는 중 / 읽고 싶은 책 으로 나눠 보기 기능
6. 검색창에 아무것도 안 쓰고 엔터 치면 화면이 하얘짐 (에러)
7. 다크 모드 있으면 좋겠다
8. 설치 방법(로컬에서 여는 법)을 문서로 정리

## 라벨 규칙
| 라벨 | 언제 붙이나 | 색 (참고) |
|---|---|---|
| `bug` | 원래 되어야 하는데 안 되는 것 | 빨강 |
| `enhancement` | 새 기능, 있으면 좋은 것 | 파랑 |
| `documentation` | 설명서·README 관련 | 초록 |
| `급함` | 화면이 깨지거나 아예 안 되는 것 (직접 새로 만들어요) | 주황 |

(앞의 세 개는 새 저장소에 기본으로 들어 있는 라벨이에요. `급함`만 새로 만들어요.)

## 이슈 제목 규칙
- `[버그] ...`, `[기능] ...`, `[문서] ...` 로 시작
- 본문에는 "무엇이 문제인지 / 어떻게 되면 완료인지" 두 줄
