# 19. 3D 기초 (Blender)

> **얻는 능력:** 3D 프로그램을 몰라도 **말로 3D 장면을 만들게** 하는 능력

**왜 배우나요?** 썸네일·쇼츠 배경에 쓸 그림을 AI 이미지로만 만들면 매번 모양이 달라져요. 3D 장면은 한 번 만들면 **각도·빛만 바꿔서 계속** 쓸 수 있어요. 블렌더는 무료예요.

## 📁 들어 있는 파일
- `장면_주문서.md` – 만들 장면 2개 (책상 위 머그컵과 화분 / 낮은 폴리 섬)
- `결과/` – 저장한 `.blend` 파일과 렌더 그림을 넣을 곳

## 📸 블렌더 낱말 5개 = 사진 스튜디오
| 낱말 | 뜻 | 스튜디오 비유 |
|---|---|---|
| 뷰포트(Viewport) | 작업하면서 보는 화면 | 스튜디오를 돌아다니며 보는 내 눈 |
| 오브젝트(Object) | 장면 안의 물건 하나 | 소품 (컵, 화분, 책상) |
| 카메라(Camera) | 최종 그림을 찍는 위치 | 삼각대 위 카메라 |
| 조명(Light) | 빛 | 스튜디오 조명 |
| 렌더(Render) | 카메라로 실제 사진을 찍는 것 | 셔터 누르기 (시간이 좀 걸려요) |

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 확인해요. **블렌더 회사가 만든 공식 MCP가 아니에요.** 개인 개발자(ahujasid)가 만든 **커뮤니티 MCP**로, 많이 쓰이고 지금도 관리돼요. 최근 이름이 `blender-mcp` → **`mcp-for-blender`**로 바뀌었어요 (옛 이름도 동작).

**1. 블렌더 설치(직접)** — blender.org에서 무료로 받아 설치해요 (3.0 이상).

**2. uv 확인** — 이 MCP는 `uvx`로 실행돼요. 이 컴퓨터엔 이미 있어요.
```bash
uvx --version
```
→ 버전 숫자가 나오면 준비 끝이에요.

**3. 블렌더 애드온 설치(직접)** — 블렌더를 닫고 실행해요.
```bash
uvx mcp-for-blender install-addon
```
→ 블렌더 안에서 Claude의 말을 받아 줄 **수신기(애드온)**를 블렌더에 넣어요. 손으로 하려면 GitHub에서 `addon.py`를 받아 블렌더 **Edit → Preferences → Add-ons → Install**로 넣어도 돼요. 설치 뒤 Add-ons 목록에서 **MCP for Blender**가 켜져 있는지 봐요.

**4. Claude Code에 연결 (이 폴더에서만)**
```bash
claude mcp add --scope project -e DISABLE_TELEMETRY=true blender -- uvx mcp-for-blender
```
→ "blender라는 이름으로 mcp-for-blender를 이 폴더에서만 쓰고, 사용 통계 보내기는 꺼 줘"라는 뜻이에요.

**5. 블렌더에서 켜기** — 3D 화면에서 `N` 키 → 오른쪽 **MCP for Blender** 탭 → 서버가 꺼져 있으면 **Start MCP Server**(버전에 따라 Connect to Claude) 클릭.

> 공식 문서(README): https://github.com/ahujasid/blender-mcp — 설치 방법이 자주 바뀌니 시작 전에 한 번 확인해요.

## ⚠️ 알아 둘 것
- 이 MCP에는 **블렌더 안에서 파이썬 코드를 마음대로 실행하는 도구**가 있어요. 그래서 **작업 전 꼭 저장(Ctrl+S)**하고, 중요한 `.blend` 파일은 열어 두지 마세요.
- 애드온은 내 컴퓨터 안(localhost)에서만 신호를 받아요. 다른 컴퓨터에서 접속하게 바꾸지 마세요.
- 다른 앱(Claude 데스크톱 등)에도 같은 MCP를 동시에 켜지 마세요. **하나만** 켜요.
- 다 쓰면: 블렌더 탭에서 서버 끄기 → `claude mcp remove blender --scope project`
