# 15. 카톡으로 결과 받기

> **얻는 능력:** Claude가 만든 요약을 **카카오톡 '나와의 채팅'으로 받아 보는** 능력

**왜 배우나요?** 요약을 아무리 잘 만들어도 컴퓨터 앞에 있어야만 보이면 잘 안 보게 돼요. 휴대폰 카톡으로 오면 이동 중에도 바로 확인해요. 비유하면 Claude가 **내 휴대폰 메모장에 쪽지를 붙여 주는** 거예요. 받는 사람은 언제나 **나 한 명**이에요.

## 📁 들어 있는 파일
- `메시지_양식.md` – 200자 안에 들어가는 요약 양식 예시, 넣으면 안 되는 정보 목록

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 확인해요.

카카오톡 '나에게 보내기'는 **Claude 데스크톱 앱에 이미 연결**돼 있어요. (카카오의 MCP 모음 서비스 **PlayMCP**를 통한 연결이에요.)
1. 데스크톱 앱 **설정 → 커넥터**에서 카카오 쪽 커넥터가 켜져 있는지 확인해요.
2. 도구 목록에서 **`KakaotalkChat-MemoChat`** 을 찾아요. 설명에 "나에게 보내는 도구, **최대 200자**"라고 적혀 있어요. → 검사표 2번에 적어요.
3. 카카오 로그인·권한 허용은 내가 직접 해요. 연결을 끊으려면 커넥터를 끄거나, 카카오 계정 → 연결된 서비스에서 해제해요.

Claude Code에서 따로 연결하고 싶다면, 공식 문서에서 최신 방법을 확인해요: https://playmcp.kakao.com
(같은 도구함에 다른 도구도 함께 담겨 있을 수 있어요. 도구함에는 **내가 설명을 읽고 이해한 도구만** 넣어요.)

## ⚠️ 알아 둘 것
- **나에게만 보내요.** 친구·단체방에 보내는 기능은 쓰지 않아요. 다른 사람에게 가는 메시지는 되돌릴 수 없어요.
- **민감한 정보는 넣지 않아요.** 나에게 보내는 것도 카카오 서버를 거쳐요. 비밀번호·인증번호·계좌번호·남의 연락처는 절대 금지.
- 한 통에 **200자**가 한계예요. 길면 잘리거나 실패해요. 보내기 전에 글자 수를 먼저 세요.
- 연습 중엔 하루 몇 통만. 너무 자주 보내면 내 카톡이 알림으로 가득 차요.

## 🧭 기본 미션 (순서대로)
1. `메시지_양식.md`를 읽고, 양식 B를 **내가 직접** 채워 "나만의 하루 요약 양식"을 만든다
2. Claude에게 그 양식으로 가짜 내용의 예시 메시지를 만들게 하고, **글자 수**를 세게 한다 (200자 이하인지)
3. 테스트 메시지 1통을 '나에게 보내기'로 보내고, 휴대폰 카톡 **나와의 채팅**에서 줄바꿈·이모지가 어떻게 보이는지 확인한다
4. 일부러 250자짜리를 만들게 하고, 보내기 **전에** Claude가 줄이거나 나누는지 본다 (실제로 보내지는 않아도 돼요)
5. **엮기:** 10강 노션 `할 일 (연습)` 데이터베이스에서 이번 주 할 일을 읽어 내 양식으로 요약 → 나에게 보낸다
6. 받은 카톡 화면을 보고, 양식에서 고칠 점 1개를 `결과/카톡_양식.md`에 적는다

## 🔥 도전 미션 (기본을 끝냈다면)
- 14강 슬랙 채널 요약 중 **내 할 일만** 뽑아 나에게 보내기
- 26강(예약 작업)에서 쓸 수 있게 "매일 아침 보낼 메시지" 만드는 문장을 미리 다듬어 두기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 건 "이게 무슨 뜻이야?"라고 꼭 물어보세요.**

```
카카오톡 도구 중 '나에게 보내기'만 쓸 거야. 다른 사람에게 보내는 기능은 쓰지 마. 이 도구의 글자 수 제한이 몇 자인지 도구 설명에서 확인해 줘.
```
```
메시지_양식.md의 양식 A 모양으로 가짜 예시 메시지를 만들고 글자 수를 세어 줘. 아직 보내지 마.
```
```
좋아, 이 메시지 그대로 나에게 보내기로 1통만 보내 줘.
```
```
노션 'MCP 연습' 페이지의 '할 일 (연습)' 데이터베이스에서 이번 주 마감인 것만 골라 내 양식으로 200자 안에 요약해 줘. 보여 주고, 내가 좋다고 하면 나에게 보내.
```
