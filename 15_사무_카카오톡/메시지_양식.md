# 카톡 '나에게 보내기' 메시지 양식 연습

> 카톡 '나에게 보내기' 도구는 **한 번에 200자**까지만 보낼 수 있어요. (공백·줄바꿈·이모지도 1자로 세요)
> 그래서 "짧고, 한눈에, 할 일 먼저"가 핵심이에요.

## 양식 A — 오늘의 요약 (예시, 가짜 내용)
```
[오늘 할 일] 12/7(월)
1. 겨울 이불 세탁소 맡기기
2. 스터디 발표자료 마무리 (마감 12/8)
3. 치과 15:00
⚠️ 내일 마감 1개
- Claude 비서
```
→ 약 80자예요. 남는 칸이 넉넉해요.

## 양식 B — 내가 만들어 볼 칸 (직접 채우기)
```
[        ] 날짜:
1.
2.
3.
⚠️
-
```

## 넣으면 안 되는 것 (나에게 보내도!)
- 비밀번호, 인증번호, 카드·계좌 번호, 주민등록번호
- API 키, 토큰
- 다른 사람의 이름·전화번호·주소
- 회사 내부 자료

## 200자가 넘으면?
1. 먼저 Claude에게 **글자 수를 세어** 달라고 해요.
2. 넘으면 "할 일 3개만 남기고 줄여 줘"처럼 **줄이기**를 먼저 해요.
3. 그래도 길면 2통으로 나누는데, 각 통에 `(1/2)`, `(2/2)`를 붙여요.
