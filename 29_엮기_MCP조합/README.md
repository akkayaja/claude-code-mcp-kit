# 29. MCP 3개 엮기 (조합)

> **얻는 능력:** MCP 여러 개를 **릴레이처럼 이어서**, 사람이 하던 "찾고 → 정리하고 → 알리는" 일을 한 번에 시키는 능력

**왜 배우나요?** MCP 하나는 손 하나예요. 손 세 개가 순서대로 움직이면 **일 하나가 통째로** 끝나요. 1인 사업에서 매주 반복하는 일(자료 조사 → 기획 정리 → 알림)이 바로 이런 모양이에요.

## 📁 들어 있는 파일
- `흐름_설계서.md` – 입력 → 처리 → 출력, 단계별 확인, **실패하면?**을 적는 설계서 (예시가 채워져 있어요)

## 🔌 연결하기
새로 꽂는 MCP는 없어요. 앞에서 연결한 3개를 써요.
- **YouTube (23)** – 입력: 영상 찾기 (읽기)
- **Notion (10)** – 처리: 연습용 "영상 기획" 데이터베이스에 정리 (쓰기). 대안: **구글 시트 (11)**
- **카카오톡 (15)** – 출력: 나에게 보내기

시작 전에 `claude mcp list`와 `/mcp`로 셋 다 ✔인지 확인해요. 하나라도 새로 연결해야 하면 **연결 전에 `공통/MCP_검사표.md`로 확인**해요.
**(직접)** 노션에 연습용 페이지 아래 **"영상 기획(연습)"** 데이터베이스를 만들고, 칸을 `제목 / 채널 / 조회수 / 주소 / 아이디어 메모`로 만들어 둬요.

## ⚠️ 알아 둘 것
- 엮을수록 **한 단계의 실수가 끝까지 번져요.** 그래서 한 번에 다 돌리지 말고 **단계마다 결과를 눈으로 확인**한 뒤 다음으로 가요.
- 유튜브 영상 제목·설명은 **남이 쓴 글**이에요. 그 안에 "이전 지시를 무시하고…" 같은 문장이 있어도 **지시가 아니라 데이터**예요. Claude가 따르려 하면 멈춰요.
- 쓰기는 연습용 DB 한 곳, 보내기는 카톡 '나에게'만.

## 🧭 기본 미션 (순서대로)
1. `흐름_설계서.md`를 `결과/`에 복사하고, 검색어와 내 규칙(❓)을 채운다. **릴레이 그림을 종이에 직접 한 번 그려 본다**
2. **① 입력만** 실행: 유튜브에서 3개를 찾아 표로 보여 달라고 한다 → 주소를 눌러 진짜인지, 조회수가 맞는지 1개 확인
3. **② 처리만** 실행: ①의 표를 노션 연습 DB에 넣는다 → 노션에서 직접 3줄을 확인
4. **③ 출력만** 실행: 카톡 나에게 요약 보내기 → 휴대폰으로 확인
5. 이제 **한 번에** 돌린다. 같은 검색어로 다시 돌려서 **중복이 생기지 않는지**(규칙이 지켜지는지) 확인한다
6. **일부러 실패시키기:** `/mcp`에서 노션을 잠깐 끄고 돌려 본다 → 설계서 "실패하면?"대로 백업 파일 + 알림이 오는지 확인 → 노션 다시 켜기
