# 00. 시작하기

> **이번에 할 일:** MCP를 확인하는 명령 3개를 익히고, 이 키트의 안전 규칙을 알아 두기

## 🔌 MCP를 한 문장으로
**MCP = Claude에게 꽂는 콘센트.** 노션 콘센트를 꽂으면 Claude가 노션을, 블렌더 콘센트를 꽂으면 블렌더를 다룰 수 있어요.

| 말 | 뜻 | 비유 |
|---|---|---|
| MCP 서버 | 프로그램과 Claude를 이어 주는 연결 장치 | 콘센트 |
| 도구(tool) | MCP가 Claude에게 주는 기능 하나하나 (예: "페이지 만들기") | 콘센트로 켜는 가전제품 |
| 범위(scope) | 이 MCP를 어디서 쓸 수 있는지 (이 폴더만 / 내 컴퓨터 전체) | 콘센트를 방 하나에만 / 집 전체에 |
| 커넥터 | claude.ai 화면에서 클릭으로 연결하는 MCP | 이미 벽에 달린 콘센트 |

## 🧭 기본 미션
터미널을 열고 이 키트 폴더로 이동한 다음, 아래 명령을 **직접** 실행해 보세요.

1. 지금 연결된 MCP 목록 보기
   ```bash
   claude mcp list
   ```
   → Claude Code에 연결된 MCP와 연결 상태(✔ / ✘)가 나와요.

2. 그중 하나 자세히 보기 (목록에 있는 이름으로 바꿔서)
   ```bash
   claude mcp get notion
   ```
   → 그 MCP가 어디에 연결돼 있고, 어느 범위에서 쓰이는지 나와요.

3. Claude Code 대화창 안에서 확인하기
   대화창에 `/mcp` 라고 입력해 보세요. → 연결된 MCP와 각 MCP의 도구 목록을 볼 수 있어요.

4. 데스크톱 앱이나 claude.ai를 쓴다면 **설정 → 커넥터** 화면도 열어 보세요. 지메일·구글 드라이브 같은 커넥터는 거기서 켜고 꺼요.

> 💡 `claude mcp list`에 안 보이는데 Claude가 쓸 수 있는 MCP도 있어요 (데스크톱 앱 커넥터). 02번에서 둘을 합쳐 지도를 만들어요.

## ⚠️ 이 키트의 안전 규칙 5가지
1. **새 MCP는 검사 후 설치:** `공통/MCP_검사표.md`로 출처와 권한을 먼저 봐요.
2. **연습 공간에서만:** 연습용 노션 페이지, 연습용 시트, 연습용 캘린더를 따로 만들어 써요.
3. **보내기·지우기·결제는 초안까지만:** 실제 실행은 내가 확인하고 직접 해요.
4. **로그인·키 입력은 내가 직접:** Claude에게 비밀번호나 키를 채팅으로 알려 주지 않아요.
5. **다 쓴 MCP는 끄기:** 연결이 많을수록 Claude가 헷갈리고 느려져요.
