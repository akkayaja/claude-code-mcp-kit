# 11. 구글 시트·드라이브

> **얻는 능력:** 구글 시트에 있는 표를 Claude에게 **검사·분류·요약**시키고 결과를 새 탭에 받는 능력

**왜 배우나요?** 가계부나 매출표는 대부분 구글 시트에 있어요. 줄이 많아지면 중복이나 오타를 눈으로 찾기 힘들어요. 이번엔 Claude가 시트를 직접 열어 보고, 문제를 찾고, 요약 탭까지 만들어 줘요. 비유하면 **꼼꼼한 경리 담당자**를 한 명 붙이는 거예요.

## 📁 들어 있는 파일
- `가계부_3개월.csv` – 가짜 가계부 3개월치 (2026년 8~10월, 91줄). **문제 3개가 숨어 있어요**
- `정답_발견할문제.md` – 숨은 문제와 월별 합계 정답 (**채점 전까지 열지 않기!**)

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 확인해요.

구글 시트·드라이브는 **Claude 데스크톱 앱의 커넥터**로 이미 연결돼 있어요.
1. 데스크톱 앱 **설정 → 커넥터**(또는 사이드바 Customize → Connectors)에서 Google Drive, Google Sheets가 켜져 있는지 확인해요.
2. 꺼져 있다면 **연결 → 구글 로그인 → 권한 허용**은 내가 직접 해요.
3. 대화창 아래 `+` → 커넥터에서 켜고 끌 수 있어요. 오늘 안 쓰는 커넥터는 꺼 두세요.

이 커넥터는 터미널의 `claude mcp list`에는 안 보여요. 02강에서 본 것처럼 **앱 쪽 콘센트**라서 그래요.
(공식 안내: https://support.claude.com/en/articles/10166901-use-google-workspace-connectors)

**연습 공간 만들기 (직접):**
1. 구글 드라이브에 새 폴더 **`MCP연습`** 을 만들어요.
2. 그 안에 새 구글 시트 **`가계부_연습`** 을 만들어요.
3. 시트에서 **파일 → 가져오기 → 업로드**로 `가계부_3개월.csv`를 올리고, "현재 시트 바꾸기"를 골라요. 탭 이름은 `원본`으로 바꿔요.

## ⚠️ 알아 둘 것
- 드라이브 커넥터는 내 드라이브 **전체**를 검색할 수 있어요. 항상 "`가계부_연습` 시트만"이라고 범위를 정해 줘요.
- **원본 탭은 고치지 않아요.** 정리한 결과는 새 탭(`정리`, `월별요약`)에 쓰게 해요. 그래야 비교할 수 있어요.
- 공유 설정 바꾸기, 파일 휴지통 보내기는 시키지 않아요.

## 🧭 기본 미션 (순서대로)
1. CSV를 직접 훑어보고 이상해 보이는 줄을 **내가 먼저** 메모해 둔다 (힌트: 3개)
2. 연습 시트를 만들고 `원본` 탭에 CSV를 올린다
3. Claude에게 시트를 읽게 하고, **중복·분류 오류·이상한 금액**을 찾아 표로 보여 달라고 한다 (아직 고치지 않기)
4. 찾은 문제를 반영한 `정리` 탭을 새로 만들게 한다
5. `월별요약` 탭에 **월 × 분류 합계표**를 만들게 한다
6. `정답_발견할문제.md`를 열어 채점하고, 결과를 `결과/가계부_점검.md`로 저장한다

## 🔥 도전 미션 (기본을 끝냈다면)
- `월별요약` 탭의 합계를 값 대신 **수식(SUMIFS)** 으로 넣게 하고, 수식이 맞는지 셀을 눌러 확인하기
- "식비가 가장 많이 늘어난 달과 이유"를 3줄로 분석받기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 건 "이게 무슨 뜻이야?"라고 꼭 물어보세요.**

```
구글 드라이브에서 '가계부_연습' 시트만 찾아서 열어 줘. 다른 파일은 열지 마. 탭 이름과 줄 수를 먼저 알려 줘.
```
```
'원본' 탭을 검사해서 중복된 줄, 분류가 이상한 줄, 금액이 튀는 줄을 표로 보여 줘. 아직 아무것도 고치지 마.
```
```
방금 찾은 문제를 고친 버전을 '정리' 탭에 새로 써 줘. '원본' 탭은 건드리지 마.
```
```
'정리' 탭으로 월별·분류별 합계를 계산해서 '월별요약' 탭에 표로 써 줘. 월별 총합도 알려 줘.
```
