# 04. 안전 체크리스트

> **얻는 능력:** 처음 보는 MCP 설명서를 읽고 **써도 되는지 / 조심해서 쓸지 / 쓰면 안 되는지** 스스로 판정하는 능력

**왜 배우나요?** MCP는 Claude에게 **열쇠 꾸러미**를 건네는 일이에요. 이름만 그럴듯한 가짜, 집 전체 열쇠를 달라는 것, 내 허락 없이 메일을 보내는 것도 있어요. 이번에 만든 검사표를 **앞으로 매 강의 시작 때** 써요.

## 📁 들어 있는 파일
- `가상_MCP_설명서/` – 가짜 MCP 설명서 5개 (전부 실제로 없는 서비스예요)
- `정답_판정.md` – 판정과 이유 (**채점 전까지 열지 않기**)
- 고칠 파일: `../공통/MCP_검사표.md` – 지금은 기본판. 이번에 **내 말로** 고쳐요

## 🔌 연결하기
이번 강의는 **아무것도 설치하지 않아요.** 설명서 안에 있는 명령은 **절대 실행하지 마세요.** 읽고 판정만 해요.
- 앞으로 새 MCP를 꽂을 때는 늘 이 순서예요: **검사표로 먼저 확인 → 판정 ✅일 때만 설치 → project 범위로**

## ⚠️ 알아 둘 것
- **빨간 깃발 5가지** 미리 보기
  1. 이름이 공식과 **한 글자만** 달라요 (가짜 의심)
  2. 내 컴퓨터 **전체**나 "전체 디스크 접근"을 달라고 해요
  3. 확인 없이 **보내기·지우기·결제**를 해요
  4. 오랫동안 **관리가 멈췄어요** (업데이트·답변 없음)
  5. 비밀번호·키를 **명령어나 채팅에 직접** 쓰라고 해요
- 컴퓨터 전체를 조종하는 MCP(예: Desktop Commander 같은 종류)도 있어요. 나쁘다는 뜻이 아니라 **할 수 있는 범위가 아주 넓다**는 뜻이에요. 연습 단계에서는 쓰지 않아요.

## 🧭 기본 미션 (순서대로)
1. `공통/MCP_검사표.md` 기본판을 읽고, 이해가 안 되는 줄에 ❓ 표시를 한다 (Claude에게 쉬운 말로 물어봐도 돼요)
2. 검사표를 **내 말로** 고쳐 쓴다. 위 빨간 깃발 5가지가 모두 들어가게, 항목은 15개 이하로
3. `가상_MCP_설명서/` 5개를 **하나씩** 내 검사표로 판정한다 → `결과/04_판정.md`에 ✅/⚠️/❌와 이유 2줄
4. 다 끝내고 `정답_판정.md`로 채점한다. 놓친 깃발이 있으면 검사표에 항목을 추가한다
5. 02번에서 만든 내 MCP 지도 중 🔴 하나를 골라 새 검사표로 다시 판정해 본다
