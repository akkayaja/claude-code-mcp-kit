# 정답_판정 (채점할 때만 열기)

> 판정 이유가 비슷하면 정답이에요. 빨간 깃발(🚩)을 몇 개 찾았는지 세어 보세요.

## 1. 메모나라 MCP (공식) → ✅ 사용
- 서비스 회사가 직접 만들었고, 공식 문서에 같은 주소가 적혀 있어요.
- 최근까지 관리됨 (9일 전 업데이트, 이슈에 답변 있음).
- 삭제·공유 도구가 **아예 없고**, 권한을 "고른 폴더만"으로 좁힐 수 있어요 → **연습 폴더만** 고르면 더 좋아요.
- 원격 연결이라 내 컴퓨터 파일을 건드리지 않고, 끊는 법이 적혀 있어요.
- 남은 주의: `update_note`는 고치기 도구예요. 연습 메모에서만 써요.

## 2. memonara-mpc → ❌ 사용 안 함 (가짜 의심)
- 🚩 **이름이 비슷한 가짜(타이포스쿼팅):** `mcp`가 아니라 `mpc`, 만든 계정도 `memonnara-0fficial` (n 두 개, 숫자 0).
- 🚩 공식과 관계 표시 없음, 6일 전에 처음 올림, 별 3개, 이슈 기능 꺼짐.
- 🚩 **비밀번호를 명령어에 직접 넣으라고 함.** 터미널 기록에 비밀번호가 남아요.
- 🚩 `delete_all_notes`, 주소를 숨긴 백업 서버로 복사(`sync_backup`) → 내 메모가 어디로 가는지 몰라요.
- 🚩 끊는 법이 없음. "더 빠르다"는 말로 공식 대신 쓰게 유도해요.

## 3. 파일정리왕 MCP → ⚠️ 그대로는 안 됨 (범위를 좁히면 고려)
- 만든 곳과 관리 상태는 괜찮아요.
- 🚩 `--root /` + "전체 디스크 접근 권한" → **컴퓨터 전체**를 열어 줘요. 열쇠 꾸러미를 통째로 주는 셈이에요.
- 🚩 `delete_file`이 휴지통을 거치지 않음, `run_command`로 아무 명령이나 실행 가능.
- 🚩 `--scope user` → 모든 폴더에서 켜져요.
- 쓴다면: `--root`를 연습 폴더 하나로, `--scope project`로, 삭제·명령 실행 도구는 쓰지 않기. 이 키트에서는 연습에 쓰지 않는 쪽을 추천해요.

## 4. 자동안부 MCP → ❌ 사용 안 함
- 🚩 **확인 없이 바로 메일 발송**, 초안 저장 기능 없음 → 이 키트 규칙(보내기는 초안까지만)과 정면으로 부딪혀요.
- 🚩 `schedule_daily`로 매일 자동 반복 → 내가 모르는 사이에 메일이 나가요.
- 🚩 권한을 골라 줄 수 없고, 주소록 **전체**를 읽어요 (다른 사람의 개인정보).
- 끊는 법이 있는 건 좋은 점이지만, 위험이 더 커요.

## 5. 날씨콕 MCP → ❌ 사용 안 함 (관리 중단)
- 읽기 도구만 있고 범위도 project라 **권한 면에서는 위험이 작아요.**
- 🚩 3년간 업데이트 없음, "보안 경고" 이슈에 답 없음, 작동 안 될 수 있다고 스스로 적음.
- 관리가 멈춘 프로그램은 구멍이 생겨도 아무도 막아 주지 않아요. 다른 날씨 방법을 찾는 게 좋아요.

## 덤: 컴퓨터 전체를 조종하는 MCP
"Desktop Commander"처럼 **터미널 명령 실행과 파일 읽기·쓰기를 컴퓨터 전체에서** 할 수 있는 MCP도 있어요. 나쁜 프로그램이라는 뜻이 아니라, **할 수 있는 범위가 아주 넓다**는 뜻이에요. 3번 파일정리왕과 같은 기준으로, 연습 단계에서는 쓰지 않고 쓸 때는 범위를 좁혀요.
