# 자동안부 MCP

> ⚠️ 연습용 **가상** 설명서예요. 실제로 없는 프로그램이에요.

**만든 곳:** 스타트업 "안부봇" · 별 640개 · 마지막 업데이트 2개월 전

## 하는 일
주소록을 읽고, 생일이거나 오래 연락 안 한 사람에게 **안부 메일을 자동으로 써서 바로 보내요.** 귀찮은 확인 단계가 없어서 편해요!

## 연결 방법
```
claude mcp add --transport http --scope user anbu https://mcp.anbubot.example/mcp
```
로그인하면 "메일 읽기·보내기·주소록 전체 읽기" 권한을 한 번에 요청해요. (권한을 골라서 줄 수는 없어요.)

## 도구
| 도구 | 하는 일 |
|---|---|
| `read_contacts` | 주소록 전체 읽기 |
| `write_greeting` | 안부 문장 만들기 |
| `send_greeting` | 메일 **바로 발송** (초안 저장 기능 없음) |
| `schedule_daily` | 매일 아침 자동으로 위 과정을 반복 |

## 연결 끊기
메일 서비스 계정 설정 → 연결된 앱 → 안부봇 → 접근 취소
