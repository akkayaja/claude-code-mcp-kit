# 18. 디자인 → 웹페이지 (Figma)

> **얻는 능력:** 피그마로 그린 화면을 Claude가 **읽고 그대로 웹페이지(HTML)로 옮기게** 하는 능력

**왜 배우나요?** 지금까지는 말로 "이런 페이지 만들어 줘"라고 했어요. 그런데 말로는 "여백 조금 넓게"가 잘 안 전해져요. 피그마는 **설계도**예요. 설계도를 보여 주면 목수(Claude)가 훨씬 정확하게 집을 지어요.

## 📁 들어 있는 파일
- `디자인_요구사항.md` – 가짜 '동네 공방 클래스 안내' 1쪽짜리 랜딩 페이지 요구사항
- `결과/` – Claude가 만든 HTML을 저장할 곳 (처음엔 없어도 돼요. 만들면서 생겨요)

## 🔌 연결하기
연결 전에 `공통/MCP_검사표.md`로 먼저 확인해요. 피그마가 **직접 만든 공식 MCP**예요.

**공식 MCP는 두 가지가 있어요**
| 종류 | 주소 | 특징 |
|---|---|---|
| 원격 서버 (추천) | `https://mcp.figma.com/mcp` | 피그마 앱 설치 없이 연결. 기능이 가장 많아요 |
| 데스크톱 서버 | 피그마 데스크톱 앱 안에서 실행 | **유료 요금제(Professional 이상)의 Dev·Full 좌석**이 필요해요 |

**1. 피그마 무료 계정 만들기** — figma.com에서 **직접** 가입해요.

**2. 키트 폴더에서 이 폴더 전용(project 범위)으로 추가** — 터미널에서 직접 실행해요.
```bash
claude mcp add --scope project --transport http figma https://mcp.figma.com/mcp
```
→ "figma라는 이름으로, 인터넷(http) 너머 피그마 공식 서버를, 이 폴더에서만 쓰게 꽂아 줘"라는 뜻이에요.

**3. 로그인(직접)** — Claude Code를 새로 켜고 `/mcp` → `figma` → **Authenticate** → 브라우저에서 권한 목록을 읽고 **Allow access**는 내가 눌러요.

> 💡 피그마는 플러그인 방식(`claude plugin install figma@claude-plugins-official`)도 안내해요. 이 키트는 범위를 좁게 쓰려고 위 방법을 써요.
> 공식 문서: https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/

## ⚠️ 알아 둘 것
- **무료(Starter) 요금제는 한 달에 읽기 도구 약 20번**까지만 쓸 수 있어요 (2026년 11월 공식 문서 기준, 바뀔 수 있어요). 그래서 **한 번에 꼭 필요한 것만** 물어봐요. 확인: https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/
- 20번을 다 썼거나 연결이 안 되면 **대체 방법**: 피그마에서 프레임을 **PNG로 내보내기** → `결과/` 폴더에 넣고 "이 그림대로 HTML 만들어 줘"라고 해요. MCP 없이도 미션을 끝낼 수 있어요.
- 커뮤니티 UI 키트를 쓸 땐 **무료·상업 이용 가능** 표시를 확인하고, 브랜드 로고가 들어간 키트는 피해요.
- 다 쓰면 끄기: `claude mcp remove figma --scope project`

## 🧭 기본 미션 (순서대로)
1. `디자인_요구사항.md`를 읽고, 종이에 **상단·소개·클래스 3개·신청 버튼** 위치를 대충 그려 본다
2. 피그마에서 새 디자인 파일 → **Frame(1440 너비)** 하나를 만들고, 요구사항대로 상자와 글자를 배치한다 (어려우면 무료 커뮤니티 UI 키트에서 랜딩 템플릿을 복제해도 돼요)
3. 프레임을 선택하고 오른쪽 클릭 → **Copy link to selection**으로 링크를 복사한다
4. 위 링크를 Claude에게 주고 **디자인을 읽게** 한 뒤, `결과/공방_랜딩.html`로 만들게 한다
5. 피그마 화면과 HTML을 **나란히 놓고** 다른 점 3가지를 직접 적는다 (색, 글자 크기, 여백)
6. 다른 점을 말로 고쳐 달라고 해서 한 번 더 맞춘다
