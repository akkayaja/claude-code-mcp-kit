# 25. 웹사이트 배포하기 (Vercel)

> **얻는 능력:** 내 컴퓨터에만 있던 웹페이지를 **인터넷 주소로 올리고, 상태와 기록을 Claude에게 물어보는** 능력

**왜 배우나요?** 가게 소개 페이지, 예약 안내 페이지, 포트폴리오… 주소가 있어야 손님에게 보여 줄 수 있어요. Vercel은 **웹페이지 무료 진열대**예요. Vercel MCP를 꽂으면 "방금 올린 거 잘 됐어? 기록 보여 줘"를 말로 물을 수 있어요.

## 📁 들어 있는 파일
- `사이트/` – 가짜 동네 공방 소개 페이지 (`index.html`, `style.css`). 연락처·실제 주소 없음
- (선택) 확장 키트에서 만든 PWA 같은 **내 결과물**을 올려도 돼요. 단, 개인정보가 없는지 먼저 확인!

## 🔌 연결하기
**연결 전에 `공통/MCP_검사표.md`로 확인**해요. (공식: Vercel이 직접 만든 원격 MCP `https://mcp.vercel.com`)

1. 키트 폴더에서 실행 (이 폴더에서만 쓰는 콘센트):
   ```bash
   claude mcp add --scope project --transport http vercel https://mcp.vercel.com
   ```
2. **(직접)** `claude` 실행 → `/mcp` → `vercel` → 브라우저에서 로그인하고, **연습에 쓸 팀(개인 계정)만** 허용해요.
3. 배포는 Vercel CLI로 **직접** 해요. 처음 한 번 로그인이 필요해요:
   ```bash
   npx vercel login
   ```
   → `npx`는 "설치 없이 한 번 빌려 쓰기", `vercel login`은 내 계정으로 로그인하기예요.

> 💡 데스크톱 앱에도 Vercel 커넥터가 있어요. 어느 쪽을 쓰든 **내 Vercel 계정과 같은 권한**을 갖는다는 점을 기억해요.
> 공식 문서: https://vercel.com/docs/agent-resources/vercel-mcp

## ⚠️ 알아 둘 것
- **배포 주소 = 아무나 볼 수 있는 게시판.** 이름·전화번호·주소·계좌 같은 개인정보는 절대 올리지 않아요.
- Vercel MCP에는 **도메인 구매·결제** 같은 도구도 있어요. 그런 도구를 쓰겠다고 하면 **거절**하세요. 이번 강의는 무료 주소(`*.vercel.app`)만 써요.
- **미리보기(Preview)** = 손님 없는 리허설 무대. **운영(Production)** = 손님이 보는 진짜 무대. 처음엔 미리보기로 확인하고 올려요.
- 원본 `사이트/`는 고치지 말고 `결과/`에 복사해서 써요.

## 🧭 기본 미션 (순서대로)
1. 원본을 복사하고 내 컴퓨터에서 먼저 열어 본다
   ```bash
   mkdir -p 25_서비스_버셀배포/결과 && cp -R 25_서비스_버셀배포/사이트 25_서비스_버셀배포/결과/monggle-site
   ```
   → `결과/monggle-site/index.html`을 브라우저로 열어 확인 (폴더 이름을 영어로 바꾼 건 배포 주소에 쓰이기 때문이에요)
2. **미리보기 배포**: `cd 25_서비스_버셀배포/결과/monggle-site && npx vercel` → 질문에 답하고 나온 **Preview 주소**를 브라우저와 휴대폰에서 열어 본다
3. Claude에게 "monggle-site 프로젝트의 최근 배포 목록과 상태를 보여 줘"라고 묻는다 → 내가 본 주소와 같은지 비교
4. **배포 기록(빌드 로그) 읽기**: 방금 배포가 어떤 순서로 진행됐는지 Claude에게 쉬운 말로 풀어 달라고 한다
5. **운영 배포 → 고치기 → 되돌리기(rollback)**: `npx vercel --prod`로 올리고, `index.html` 맨 아래를 `버전 2`로 고쳐 다시 `--prod` 배포. 그다음 대시보드의 **Instant Rollback**(또는 Claude에게 되돌리기 **미리 설명만** 요청)으로 버전 1로 돌아가는 걸 확인한다. 비유: 게임의 **세이브 포인트로 돌아가기**

## 🔥 도전 미션
- 확장 키트에서 만든 PWA를 배포해 휴대폰 홈 화면에 추가해 보기
- 일부러 `index.html`의 CSS 경로를 틀리게 배포해 보고, Claude에게 "왜 디자인이 깨졌는지" 배포 파일 목록으로 찾게 하기
