# 클로드 코드 MCP 키트 (32강)

**MCP**는 Claude에게 다른 프로그램을 다룰 **손**을 달아 주는 연결 규격이에요. 콘센트 규격처럼, 규격만 맞으면 노션·구글·블렌더·카카오톡까지 Claude가 직접 다룰 수 있어요.

이 키트에서는 **사람들이 많이 쓰는 MCP**를 하나씩 연결해 보고, 여러 개를 엮어 일을 자동으로 처리하고, 마지막엔 **나만의 MCP**를 만들어요.

## 시작
**`00_시작하기/README.md`를 먼저 하세요.** MCP 확인 명령과 이 키트의 안전 규칙이 들어 있어요.

## 진행 방법
- **01~04는 꼭 먼저** 하세요. 특히 04번에서 만드는 `공통/MCP_검사표.md`로 **매 강의 시작 때 MCP를 검사**해요.
- 그다음은 부 단위로 골라서 해도 돼요. 단, 같은 부 안에서는 번호 순서를 지켜 주세요. 29번부터는 앞에서 연결한 MCP를 써요.
- 원칙은 그대로예요: **먼저 직접 보고 추측 → Claude에게 묻기 → 내 눈으로 검증**
- 모든 연습 데이터는 **가짜**예요. 각 서비스에는 **연습용 공간**(연습용 노션 페이지, 연습용 시트, 연습용 캘린더 등)을 따로 만들어서 써요.
