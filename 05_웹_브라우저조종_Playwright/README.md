# 05. 브라우저 조종 (Playwright)

> **얻는 능력:** Claude에게 **브라우저를 직접 움직이게** 해서, 여러 쪽짜리 웹페이지 정보를 표(CSV)로 모으는 능력

**왜 배우나요?** "이 사이트 1~3쪽 목록을 엑셀로 정리해 줘" 같은 일, 손으로 하면 복사·붙여넣기 지옥이에요. Playwright MCP를 꽂으면 Claude가 브라우저를 열고, 클릭하고, '다음' 버튼을 눌러 가며 모아 와요.

## 📁 들어 있는 파일
- `연습사이트/` – 가짜 동네 중고서점 "책갈피" (책 18권, 3쪽, 한 쪽에 6권)
- `정답_수집결과.csv` – 모두 제대로 모았을 때의 결과 (**채점 전까지 열지 않기**)

## 🔌 연결하기
Playwright MCP는 **마이크로소프트가 직접 만든 공식 MCP**예요. 내 컴퓨터에서 브라우저를 띄워요.
1. **검사표로 먼저 확인:** `공통/MCP_검사표.md` (출처: github.com/microsoft/playwright-mcp)
2. 키트 맨 위 폴더에서 직접 실행해요.
   ```bash
   claude mcp add --scope project playwright -- npx @playwright/mcp@latest --isolated
   ```
   - `npx @playwright/mcp@latest` : 공식 패키지 최신판을 받아서 켜요
   - `--isolated` : 쓰고 나면 기록이 남지 않는 **새 브라우저**로 열어요. 평소 쓰는 크롬의 로그인 정보와 섞이지 않아요
3. Claude Code를 다시 켜고 프로젝트 MCP 사용을 **직접 승인**해요. `/mcp`에서 `browser_navigate`, `browser_snapshot`, `browser_click` 같은 도구가 보이면 성공이에요.
4. 공식 문서의 기본 명령은 `claude mcp add playwright npx @playwright/mcp@latest`예요. 최신 명령은 공식 문서에서 확인해요: https://github.com/microsoft/playwright-mcp

## ⚠️ 알아 둘 것
- 연습은 **내 컴퓨터의 연습사이트(localhost)**에서만 해요. 로그인이 필요한 사이트, 쇼핑·결제 페이지는 Claude에게 맡기지 않아요.
- 브라우저 창에 **비밀번호를 대신 입력하게 하지 않아요.** 로그인이 필요하면 내가 직접 해요.
- 진짜 사이트를 모을 때는 그 사이트의 이용 약관을 먼저 봐요. (07번에서 더 배워요)
- 다 쓰면 `/mcp`에서 끄기. 브라우저 도구는 할 수 있는 일이 많아요.

## 🧭 기본 미션 (순서대로)
1. 터미널 하나를 새로 열고 연습사이트를 켠다: `cd 05_웹_브라우저조종_Playwright/연습사이트` → `python3 -m http.server 8780` (끌 때는 `Ctrl + C`)
2. **추측 먼저:** 내 브라우저로 http://localhost:8780 을 열어 보고, 전체 몇 권인지·품절이 몇 권인지 짐작해 적는다
3. Playwright를 연결하고, Claude에게 첫 쪽의 책 제목 6개만 읽어 오라고 한다. 새 브라우저 창이 뜨는지 지켜본다
4. **1~3쪽 전체**를 '다음' 버튼으로 넘겨 가며 모아 `결과/중고책_목록.csv`로 저장하게 한다
   - 열: `제목, 지은이, 펴낸해, 상태, 가격, 판매상태, 쪽` (가격은 숫자만, 쉼표·'원' 빼기)
5. **내 눈으로 검증:** CSV를 열어 18줄인지, 품절 3권이 맞는지, 아무 책 2권을 사이트와 비교한다
6. `정답_수집결과.csv`와 비교해 채점한다. 다른 줄이 있으면 왜 달랐는지 Claude에게 물어본다

## 🔥 도전 미션
- "가격 5,000원 이하 + 상태 '상'"인 책만 골라 따로 표로 만들기
- 휴대폰 크기로 창을 줄여 스크린샷을 찍게 하고(`결과/` 폴더에 저장), 화면이 깨지지 않는지 보기
- 같은 일을 Playwright 없이 "파이썬 코드로 모아 줘"라고 해 보고, 두 방법의 차이를 3줄로 정리하기
