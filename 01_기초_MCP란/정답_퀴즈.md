# 정답_퀴즈 (채점할 때만 열기)

1. **(나)** 콘센트(MCP 서버)에 꽂아서 쓰는 가전제품 하나하나가 도구예요.
2. **(다)** `search_statistics`는 KOSIS MCP가 주는 도구 이름이에요. 노션은 서비스, `claude mcp list`는 확인 명령, `.mcp.json`은 설정 파일이에요.
3. **(나)** MCP 없이 나온 숫자는 기억에서 나온 것일 수 있어요. 틀렸다고 단정할 수는 없지만, 기준 연도와 출처를 꼭 확인해요.
4. **(나)** project(팀과 공유, `.mcp.json`) 또는 local(나만, 이 폴더에서만). user는 내 컴퓨터의 모든 폴더예요. 자세한 건 03번에서 배워요.
5. **커넥터** – 이미 벽에 달린 콘센트처럼, 앱 설정에서 켜고 끄기만 하면 돼요.
6. **X** – Disable은 잠깐 끄는 것이에요. 완전히 지우려면 `claude mcp remove 이름`을 써요.
7. **X** – 연결이 많으면 Claude가 어떤 도구를 쓸지 헷갈리고, 느려지고, 위험한 도구가 늘어나요. 필요한 것만 켜 두는 게 좋아요.
8. 예시 답: "MCP가 없으면 내 노션 페이지를 못 읽지만, 노션 MCP가 생기면 페이지를 읽고 새 페이지도 만들 수 있다." 서비스 이름과 할 수 있는 일이 들어가 있으면 정답이에요.

**채점:** 7개 이상 맞으면 02번으로! 5개 이하면 00번 표와 이 강의 용어표를 한 번 더 읽어 보세요.
