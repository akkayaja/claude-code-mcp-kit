# 01. MCP란?

> **얻는 능력:** MCP가 **있을 때와 없을 때** Claude가 할 수 있는 일이 어떻게 달라지는지 직접 보고 설명하는 능력

**왜 배우나요?** Claude는 똑똑하지만, 콘센트가 없으면 노션도 통계청도 못 열어요. 같은 질문을 MCP 없이 한 번, MCP를 켜고 한 번 해 보면 "MCP = 손을 달아 주는 콘센트"라는 말이 몸으로 이해돼요.

## 📁 들어 있는 파일
- `퀴즈.md` – 용어 확인 퀴즈 8문제
- `정답_퀴즈.md` – 정답과 해설 (**채점 전까지 열지 않기**)

## 🔌 연결하기
이번 강의는 **새로 설치하지 않아요.** 이미 연결된 MCP를 켰다 껐다만 해요.
- 데스크톱 앱: 대화창 아래 **＋ 버튼(또는 도구 메뉴) → 커넥터 목록**에서 켜고 끌 수 있어요.
- Claude Code: 대화창에 `/mcp` → MCP를 골라 **Disable / Enable**. 설정은 지워지지 않고 잠깐 꺼지기만 해요.
- 통계청(KOSIS) 커넥터나 노션처럼 **이미 연결돼 있는 것** 하나를 골라요. 둘 다 없다면 비교 미션은 08번 강의 때 다시 해도 돼요.

## 📖 용어 4개 (00번 표 복습)
| 말 | 쉬운 뜻 | 비유 |
|---|---|---|
| MCP 서버 | 프로그램과 Claude를 잇는 연결 장치 | 콘센트 |
| 도구(tool) | MCP가 주는 기능 하나 (예: `search_statistics`) | 콘센트에 꽂은 가전제품 |
| 범위(scope) | 그 MCP를 어디서 쓸 수 있나 | 방 하나 / 집 전체 |
| 커넥터 | 앱 화면에서 클릭으로 연결하는 MCP | 이미 벽에 달린 콘센트 |

## ⚠️ 알아 둘 것
- MCP를 끈 상태에서 Claude가 숫자를 말하면, 그건 **기억으로 짐작한 숫자**일 수 있어요. 진짜 확인한 숫자인지 꼭 물어보세요.
- 끄고 켜는 건 안전해요. 지우는 건 03번에서 배워요.

## 🧭 기본 미션 (순서대로)
1. **추측 먼저:** "통계청 1인 가구 비율 최신 수치"를 Claude가 MCP 없이 정확히 알 수 있을지 내 생각을 한 줄 적는다
2. **끄고 묻기:** KOSIS 커넥터(또는 노션)를 **끈 채로** 아래 '이렇게 말해 보세요' 첫 문장을 보낸다. 답과 "어디서 가져왔는지"를 적어 둔다
3. **켜고 묻기:** 커넥터를 **켜고** 같은 문장을 보낸다. 이번엔 Claude가 어떤 **도구 이름**을 불렀는지 화면에서 찾아 적는다
4. **비교표 만들기:** `결과/01_비교.md`에 두 답을 나란히 놓고 (숫자 / 출처 / 기준 연도 / 믿을 만한가) 4줄로 비교한다
5. **퀴즈 풀기:** `퀴즈.md`를 풀고, 다 푼 뒤에 `정답_퀴즈.md`로 채점한다

## 🔥 도전 미션
- 노션 MCP로 같은 실험: 연습용 노션 페이지 제목을 MCP 없이 / 있이 물어보기
- 내가 쓰는 MCP 하나를 골라 "콘센트·가전제품" 비유로 친구에게 설명하듯 3줄 써 보기
